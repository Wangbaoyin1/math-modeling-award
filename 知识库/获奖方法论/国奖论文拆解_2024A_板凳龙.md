# 国奖论文拆解（2024 A·板凳龙运动状态与路线）

> 深拆 58 页完整国一论文（全国一等奖 + 北太天元数模之星），运动学+优化题范式。
> 标题：《基于动态搜索的"板凳龙"运动状态及路线研究》
> 方法主链：**极坐标运动学递推 + 几何碰撞判据 + 动态搜索(变步长+二分/三分) + PSO 单目标优化**

## 一、题目与挑战

223 节板凳（1 龙头 3.41m + 221 龙身 2.20m + 1 龙尾），沿等距螺线盘入 → 调头 → 逆时针盘出。
难点：① 多体刚性链的**逐节递推位置/速度**（223 节，每秒都要算）；② 碰撞判定（何时停）；③ 最小螺距优化；④ 调头路径四段曲线拼接的递推**分类讨论**；⑤ 龙头限速优化。

## 二、五问解法链（完整运动学题范式）

| 问 | 模型 | 核心方法 | 关键数值 |
|----|------|---------|---------|

| 二 | 碰撞检测模型 | **先证明碰撞只发生在最内圈vs相邻圈** → 点到直线距离 < 半板宽0.15m → 变步长粗搜+二分精搜 | **停盘时刻 412.473838s** |

## 三、核心创新点（值得抄的"建模套路"）

### 创新 1：先证明后缩小——"剪枝式"碰撞检测 ★★★
不直接 223×223 全对检测，而是**先证明**（极角速度内圈>外圈 → 相对位置变化快 → 更易碰撞；且龙头最长最靠外）碰撞必然最先发生在**龙头所在最内圈与其外侧相邻一圈**之间 → 检测范围从全链降到"内圈 vs 邻近 5 块"。
> 套路：**用物理论证把 O(n²) 剪成 O(n)**——省算力只是表面，评委看到的是"物理直觉 + 严谨证明"，这是 A 题高分核心。

### 创新 2：链条递推的"极坐标 + 余弦定理"框架 ★★★
整条龙 223 节不直接求笛卡尔坐标，而是：
1. 龙头在螺线 r=dθ/2π 上，速度恒定 → 解 θ₀(t) 微分方程（**二分搜索反解**，因等号右边单调）；
2. 相邻把手 l²=rₙ²+rₙ₊₁²−2rₙrₙ₊₁cos(Δθ) → **递推解 θₙ₊₁**（含龙头 l=2.86m/龙身 l=1.65m 分节几何）；
3. 两边对 t 求导 → **角速度递推** → vₙ = (d/2π)|θ̇ₙ|√(1+θₙ²)。
> 套路：**跟运动学链式问题，"主驱动体解析 + 链节几何递推 + 求导得速度"一次搭好全队框架**，后续每问复用。

### 创新 3：碰撞判据 = 几何距离 vs 物理安全阈值
把"碰撞"翻译成**顶点到相邻板凳中心线(把手连线)的距离函数**：d_A(t,i,j)、d_B(t,i,j) 用点到直线公式，任意 < 0.15m（半板宽）即撞。
> 套路：物理问题先做**几何理想化（把手=点、板=线段/矩形）**，再给可计算的解析判据——比单纯"圆心距<半径"式判据高级，且能画出**最短距离-时间曲线**（红线 y=0.15 交叉点=碰撞时刻）作为验证图。

### 创新 4：目标转化的巧劲（问题五）★★
不直接解"龙头最大速度"，而是利用速度线性：**所有把手速度 ∝ 龙头速度**，故在龙头=1m/s 的基准上求出最大把手速 v*=1.6048，则 v_max = 2/v*·1 = 1.246m/s。
> 套路：**遇到带约束的自由参数（未知龙头速度），先固定它算结构量，再按线性关系还原**——把优化问题变成"搜索函数极值"。

### 创新 5：求解器选择的"论证 + 对比"（问题三）
dis(t) 局部极小多、峰高，作者**明确对比模拟退火 vs 粒子群**，论证"SA 易陷局部极小难以越障，PSO 全局搜索强"后选 PSO（粒子 40、迭代 50、ω=0.8、c₁=c₂=0.5），并给收敛过程图证明。
> 套路：**不说"我用了 PSO"，而说"我试了 SA 不行，PSO 因 XX 更合适"**——算法选择要讲理由，收敛图 + 多次实验稳定性 = 说服力。（呼应我失败模式 #6/#7：多策略混合、别锁死单一方法。）

## 四、模型检验（运动学题四件套）

1. **可视化验证**：绘制各时刻板凳龙状态模拟图（t=412s 时龙头顶点恰与外圈临界），肉眼确认；
2. **数值微分交叉验证**：用 0.01s 小步长位移差商算平均速度，与解析求导对比（差异小→模型正确）；
3. **物理规律自查**：越靠内圈极角变化越快（半径小）、越靠外速度衰减越多——与运动学直觉一致；
4. **极值曲线图**：最短距离随时间曲线（问题二）、dis(t) 随 d 单调上升曲线（问题三，证明变步长不漏解）、速度最大值曲线（问题五，证明单峰可三分）。
