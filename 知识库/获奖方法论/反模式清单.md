# 反模式清单（致命错误自查）

> 用途：写作前 / 写作中 / 终审前三个时点各扫一遍。**每条都是真实国奖论文复盘里的"扣分/翻车"点。**
> 来源：内化自 anti-patterns 清单 + 国奖论文复盘。

## 一句话核心

国奖论文的失败，大多不是"不会做"，而是**踩了本可避免的反模式**。这个清单就是"雷区地图"——命中即修。

## 八大类反模式（每类最致命的 2-3 条）

### A. 摘要类（扣分最重，权重 30%+）
- **A1 摘要无定量结果**：写"得到较好结果" → 改"得到最优配比(0.42,0.31,0.27)，误差 1.8%"。
- **A2 摘要结构混乱**：一段 800 字 → 严格四段式（问题+挑战 / 方法 / 关键结果 / 验证+创新）。
- **A3 摘要与正文不符**：摘要说 LSTM、正文是 BP → **摘要最后写**，基于定稿正文。

### B. 假设符号类
- **B1 假设无支撑**：孤立一句"假设匀速" → 加依据"附件2显示 95% 行程速度方差<5km/h"。
- **B4 符号重复定义**：λ 在 Q1 是衰减、Q2 是乘子 → 全文符号表统一，不同含义用下标。
- **B7 量纲不一致**：第一章 km、第二章 m → 全程统一单位。

### C. 模型选型类
- **C1 直接抄课本模型**：写"采用 AHP" → 命名变体 + 说明改进点（"动态权重 AHP-熵权混合"）。
- **C2 模型与问题不匹配**：要分类却用回归 → 对照题型决策树。
- **C3 候选模型同族**：BP/RBF/LSTM 全是神经网络 → 候选要 **≥2 个结构性不同的族**。

### D. 求解类
- **D2 不做 sanity check**：求解器结果直接用 → 至少验一个边界 case。
- **D4 不固定随机种子**：每次跑结果不一样 → `np.random.seed(42)` 全文统一。
- **D6 局部最优当全局**：只跑一次梯度法 → 多初值跑 + 报最优性差距。

### E. 结果分析类
- **E1 只报数字不解读**：写"X=12.3" → 加"意味着每天最多调度 12 辆，与现实 10-15 辆一致"。
- **E5 灵敏度只拉 ±20% 不重新求解**（最隐蔽的错）：改参数后**必须重新求解整个模型**，最优解会移动！
- **E6 灵敏度参数乱选**：随便挑几个 → 先全局扫描找敏感参数。

### F. 写作结构类
- **F1 跳过问题分析直接建模**：缺"为什么用这个方法" → 先题型判断→选型对比→再建模。
- **F4 引用百度百科** → 用知网/期刊论文。
- **F6 创新点牵强**：写"创新在于用了神经网络" → 创新要来自问题结构/约束设计/算法改进。

### G. 灵敏度与稳健性类
- **G1 完全不做灵敏度**：国一标配，没有=致命伤 → 留专门一章。
- **G3 灵敏度无决策建议**：只画曲线说"稳定" → 加"决策者应优先测参数 X，因 Y% 变化逆转结论"。

### H. 流程类
- **H1 最后一天还在写代码** → 第 3 天锁代码，最后 24h 只写作。
- **H2 第 3 天还在纠结选题** → 第 1 天前 4h 果断定题。
- **H3 摘要最后 30 分钟写** → 至少留 2 小时专写摘要（权重最高）。

## 使用方式

- **写作前**：扫 A/B/C 类（摘要、假设、选型），避免结构性错误
- **写作中**：扫 D/E 类（求解、结果），避免数值与呈现问题
- **终审前**：全表逐条对照，命中即修
- **特别盯 A 类**：摘要权重最高，A1/A2/A3 是最常见失分点

## 验收题（学习闭环）

> 一篇论文的敏感性分析写的是："将参数 α 在 ±20% 内变化，代入公式计算，结果变化 <5%，模型稳健。"
>
> 请回答：① 这踩了哪条反模式？② 为什么这样是错的？③ 正确的做法是什么？
