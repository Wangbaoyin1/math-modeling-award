# 老哥·赛题类型与建模方案（p98 视频学习笔记）

> 来源：老哥 p98「常见赛题类型及建模方案」，方法选择决策树（老哥版）。

## 一、三大赛题类型

| 类型 | 细分 | 说明 |
|------|------|------|
| 评价类 | 主观评价 / 客观评价 | |
| 预测类 | 大样本预测 / 中小样本预测 | |
| 优化类 | 静态优化 / 动态优化 | **最常见，几乎每年都考，必掌握** |

## 二、评价类方法选择决策树（关键！）

| 条件 | 选方法 |
|------|--------|
| 数据量少、评价指标少 | 层次分析法 AHP |
| 数据量小、样本有时间序列特性 | 灰色关联分析 |
| 指标较多、各指标相互独立 | TOPSIS 综合评价 |
| 经济等领域、多因素多层次复杂问题 | 模糊综合评价 |
| 评价新颖问题、传统方法难获权重 | 神经网络 |
| 多种投入多种产出 | 数据包络法 DEA |

## 三、预测类两类

1. **无法用数学刻画内部机理** → 数据驱动（时间序列 / 灰色 / 神经网络）
2. **可用微分方程刻画内部规律** → **机理建模**（微分方程）

## 四、优化类解题四步

```
确定决策变量 → 确定目标函数 → 确定约束条件 → 给出最优结果
     ↓               ↓                ↓
  (优化谁)      (优化目的)       (客观限制)
```
映射规划类型：线性 / 非线性 / 整数 / 0-1 / 多目标 / 动态规划。

**精确求解**：无约束凸函数可导 → 梯度下降（随机初始解，沿梯度迭代到导数够小）。

## 五、与我的工具箱呼应（强化）

- 评价决策树 = 我的 `T2_评价类`（AHP/熵权/TOPSIS/模糊/灰色）的**选择规则补充**（原来只列了候选，这里给了"什么条件选谁"）。
- 预测两类 = 我的 `T3_预测类` + `T5_机理类` 的分类。
- 优化四步 = 我的 `T1_优化类`。

> 这条决策树是最实用的"选题型→选方法"速查，建模时先查它。
