# 降重 · 降 AI 味 双检硬规范（查重与AI痕迹双重自检）

> 来源：《降重与降低AI味讲义.pdf》（2026国赛降重降AI速成课）逐页学习 + 内化 de-ai-writing。
> 定位：`降AI写法.md`（v3，侧重"AI写作人味"）的**补充与兄弟篇**——本文件把**降重复率(查重)** 和 **降AI味** 的**可执行方法 + 双检清单**合并，二者在国赛里是**两条独立红线**，都要过。
> 用法：Phase 3 论文终稿前，**先降重（查重）→ 再降AI味 → 逐条核对论文本身是否满足**，缺一项即回退。
> **⚠️ 落地原则（对应 #25 教训）**：双检是**降重/降AI味的实质要求**——每条都要在**论文正文里真实体现**（真数据替换、段落交錯、有研究痕迹），**不是要 agent 另写一份"检测记录/打勾清单"文档去证明达标**。不要为产出记录而空转，检查项进论文、跑完就交付（像 2026B 那样干净）。

## 〇、先认清：查重 和 AI检测 是两回事

| 维度 | 文档查重/相似度 | AIGC 检测 |
|---|---|---|
| **查什么** | 与数据库/网页/论文/往届作品比较 | 依据句法、概率、节奏、用词分布等语言特征分类 |
| **主要风险** | 照抄、句式骨架高度相似、引用不规范 | 段落过整齐、套话密集、内容泛化、证据不足 |
| **最有效办法** | 重新理解后重写；规范引用；加入自己的数据与结果 | 补真实决策与实验细节；改结构与节奏；人工写作核验 |
| **最差办法** | 机械同义词替换、机器洗稿 | 故意错别字、乱加口语、机械删连接词、只靠去AI提示词 |
| **能否代表质量** | 不能 | 不能 |

**核心铁律（背下来）**：
> **规则优先级 = 独立完成 > 真实准确 > 规范引用 > AI透明披露 > 语言美观。**
> **AI率<5%≠安全，重复率<10%≠拿奖。** 官方没有公布统一合格线，不同平台算法不同，可能误检/漏检。检测结果只是**风险信号**，不能代替质量。

## 一、降重（降低文档重复率）

### 原理：降重四层功力（越往上越原创）
```
词汇层(换词) < 句法层(换句式) < 逻辑层(改信息顺序) < 证据/事实层(加本题变量/数据/图表/结果)
```
> 只停留在换词 = 低质量洗稿（最差）；**加入属于本题、属于本队的真实证据 = 最原创、最有效**。

### 六个真正有效的方法
1. **摘要式重写**：原段落压缩成 3-5 个信息点，**关掉原文**，再按自己逻辑展开——切断对原句语序依赖。
2. **改变信息顺序**：`背景→问题→方法→意义` 改成 `现实问题→约束→为什么需要该方法→本题怎么做`；**但不能破坏因果**。
3. **抽象—具体转换**：先抽象成一般概念，再结合本题具体化（`配送车辆`→`多约束路径优化`→写本题容量/时间窗/拥堵参数）。
4. **引用后解释**：经典定义/官方规则/关键数据**不必硬洗**——规范引用后用自己话解释"为何与本题有关、本文怎么用"。
5. **用自己的结果替换套话**：把`模型效果较好`换成具体 **MAE/RMSE/误差分布/运行时间/排名变化/参数敏感区间**。
6. **让图表承担信息**：流程/参数表/对比结果放原创图表，正文只解释关键发现，减流水账。

### 经典定义怎么写（定义:引用；方法:说明本题怎么用；结果:写自己数据）
```latex
本文采用灰色关联分析衡量各指标与目标序列的变化一致性，
具体计算按文献[1]进行；在本题中，分辨系数取 0.5，并按式(12)得到各指标关联度。
```

### ⚠️ 不能乱降的内容（改了=技术事故）
- 公式与推导（不能为改写改数学含义）
- 变量与符号（全篇一致，不临时换）
- **模型名称**（ARIMA/TOPSIS/K-means/XGBoost 标准名词无需降重）
- 数值与单位（只能源于真实数据/计算输出）
- 图表编号（图3/表5/式(7)必须与正文对应）
- 算法执行顺序（依赖关系严格不随意打乱）
- 引用内容（官方规则/题目数据/文献结论保持来源清晰）

### 高重复段落的"错误洗稿"范例（绝不学）
```
原：车辆路径规划是降低物流成本和提高配送效率的重要手段……
错：车辆线路优化是降低运输费用和提升配送效能的关键方法……（只换词，逻辑结构不变=低质洗稿）
```

### 文献综述最容易重复 → 怎么改
❌ 低质：`张三提出A；李四提出B；王五提出C`（每篇1句缺比较，最后"综上研究很多仍不足"）
✅ 高质量：**按问题分类** + **比较数据/假设/优缺点/与本题差异** + **指出具体缺口** + **说明本文为何选某模型哪里改**。

### 摘要降重：不要写成万能模板
❌ 模板：`针对……问题，本文建立……模型。首先……其次……最后……结果良好。`
✅ 示范：`针对配送路线同时受容量、时间窗和早高峰拥堵影响，本文把路段通行时间写成__，用__求解。最优总里程193.1km，较纯最短路增加3.6%，但时间窗违约由4次降为0。对拥堵系数±20%扰动后，路线主干不变。`

### 用工具先自检
- Word/WPS"查找"：把模板化完整句复制进来全文找重复，看是否每节同一种句式；
- 搜索引擎引号检索：8-15 连续词加引号搜，看是否与网文高度一致→一致则引用或重写；
- Word"比较文档"：保存原稿 vs 修改稿，直观看哪些只是换词、哪些真重组。

## 二、降 AI 味

### 先定义"AI味"
> **AI味 = 模板化结构 + 过度平滑语言 + 泛化内容 + 缺少真实决策痕迹。**
> 同一句"值得注意的是"，后接关键异常现象（如"λ<0.8时第2方案排名第5升到第2"）就不突兀；每段都用来引空泛总结就机械。

### 九类常见 AI 痕迹（自查命中即改）
1. **句长过于均匀**（每句20-30字、每段4-5句，同一个模具）
2. **段落过于对称**（每小节都"背景—三点—总结"，每个观点硬凑三条）
3. **过渡词密度过高**（首先/其次/最后/此外/进一步/综上连续出现）
4. **"不是X，而是Y"过密**（用否定对比制造深刻感，信息增量小）
5. **抽象大词过多**（赋能/重构/机制/维度/范式/闭环/协同，却不说具体变量和操作）
6. **内容正确但空泛**（提高准确性/增强鲁棒性/有重要意义，却没指标实验数字）
7. **结果永远完美**（无异常样本/失败方案/敏感区间，全部分析顺利闭环）
8. **引用与判断分离**（文献堆句末，没说哪篇影响了哪项选择）
9. **语言水平突然跳级**（前面普通学生写法，某节突然复杂长句+高阶术语）

### 六大类降低方法（内容/结构/节奏/套话/用图倒逼/角色转换）

**① 内容**：
1. 结论前先做证据表（每个结论对应数据/图/公式/代码输出/文献/异常样本，无证据不写肯定）
2. 写模型选择理由（为什么不是线性回归/XGBoost，与本题数据关系）
3. 写参数来源（学习率/窗口/惩罚系数从哪来：网格搜索/经验/文献/数据分布）
4. 写失败方案（试过两模型其一差，简短写为何舍弃）
5. 写异常点（最大误差样本/排名变化节点/敏感区间/极端情景）
6. 写边界条件（明确何时有效、何时可能失效）

**② 结构**：
- 定义段可只2句；模型推导段可较长；结果解释有时只需一句
- 不要每节都"三点式"（两点能说清就两点）
- 不每段结尾都加"因此本文有重要意义"，很多段可自然结束
- 把`目的—方法—结果—总结`改成更贴合研究过程的`观察—解释—决策`
- 有三级标题就不要重复"首先/其次/最后"（标题已说清）

**③ 句子节奏**：
- 长短句搭配：复杂推导可长，结论句尽量短
- 一句只承担一个主要任务（别同时塞背景+方法+结果+意义）
- 少用连续排比（提高准确性、增强鲁棒性、提升可解释性——无证据就删）
- 破折号/冒号/括号只在有功能时用，不为"高级感"堆符号
- 具体主语：`图6显示`/`测试集结果`/`λ增大后`，比`研究结果表明`更具体

**④ 减少高频套话（不做机械禁词表）**：
| 模板 | 问题 | 更适合 |
|---|---|---|
| 值得注意的是，模型显著提升了性能 | 强调词多证据少 | 测试集RMSE由1.84降至1.57 |
| 在此基础上，进一步构建综合评价体系 | 信息为空 | 分别比较成本、等待时间和违约率 |
| 从多个维度进行深入分析 | 评价空泛 | 参数±20%扰动时前三名不变 |
| 模型具有良好的鲁棒性 | 万能结尾 | 删掉，或写具体结论 |
| 赋能/重构/颠覆 | 容易夸张 | 写清楚具体改进了什么 |
| 研究范式/发展范式 | 常被滥用 | 若只是模型框架就直接写模型/框架 |

**⑤ 用"自己的图"倒逼自己的文字**（最有效，天然具体）：
1. 只看图，不看AI生成文字
2. 写3条肉眼观察（"第4-6小时增长最快""参数>1.2后曲线趋于平稳"）
3. 回程序输出确认数字（避免凭视觉估计）
4. 写原因，区分"数据直接支持"和"可能解释"
5. 最后补一句与模型决策相关结论（"因此取λ=1.0"）

**⑥ 把AI从代写者改成审稿人**（关键！改变使用方式=天然降AI+合规）：
| ❌ 不推荐 | ✅ 更推荐 |
|---|---|
| 帮我写完整的模型建立章节 | 检查我这节变量定义和公式编号是否一致 |
| 帮我降AI率到0 | 指出哪些句子空泛缺少证据，不要替我重写 |
| 模仿优秀大学生写作，整段重写 | 只标出过长句和冗余连接词，给局部改法 |
| 自动生成参考文献 | 根据我提供的真实文献核对引用位置，不新增文献 |
| 替我解释图8 | 根据我写出的3条观察，检查是否存在逻辑跳跃 |

## 三、双检清单（终稿前逐条过，缺一即回退）

### A. 降重（查重）检
- [ ] 无大段照抄公开资料；引用他人观点/数据/定义/方法都标注来源并入参考文献
- [ ] 无"同义词洗稿"（只换词不动结构）的段落
- [ ] 每个模型/方法都说明"为什么选它、数据怎么处理、参数怎么定、结果怎么解释"
- [ ] 套话替换成自己的真数据（MAE/RMSE/误差分布/运行时间/敏感区间）
- [ ] 变量/符号/模型名/数值/单位/图表编号 全篇一致未被篡改
- [ ] 公式推导、算法顺序未被"降重"破坏

### B. 降 AI 味检
- [ ] 句长有长短交替（无"每句20-30字/每段4-5句"的均匀感）
- [ ] 段落不对称（无每节"背景-三点-总结"模板；无每观点硬凑三条）
- [ ] 无过渡词堆砌（首先/其次/最后/此外/进一步/综上）
- [ ] 无"不是X而是Y"过密；无抽象大词连用（赋能/重构/范式/闭环）
- [ ] 每个结论有证据（数据/图/公式/代码/异常样本）
- [ ] 有模型选择理由 + 参数来源 + 失败方案 + 异常点 + 边界条件
- [ ] 有"意外发现/排查过程"（AI不会犯错再纠正，最强人味信号）
- [ ] 图表标题说"发现了什么"而非"是什么"
- [ ] 结果分析用"观察—解释—决策"，非"目的-方法-结果-总结"
