# 国奖论文拆解（2024 B·企业生产过程的决策优化）

> 深拆 2024B 国二（福建赛区推荐国一、全国终评国二；顾国勤/杨子慧/吕阳）——**0-1 决策优化题**。
> 仓库无 PDF（代码 + readme 思路），本拆解基于 readme 数学模型 + Q2/Q3-GA/Q3-PSO/Q4 全部代码。
> 方法主链：**递归期望成本解析（几何级数求和）+ 蒙特卡洛仿真互证 + GA/PSO 搜 13 个 0-1 决策**

## 一、题目与挑战

多工序生产：零配件(次品率 rᵢ)→检测(成本 icᵢ)→装配→(半成品)→成品→检测→出售/调换/拆解。问：
- 每道环节**要不要检测？不合格成品要不要拆解重装？**（答 6 个独立案例）
- 题内隐含**无限递归**：检出次品→换新→可能再坏→再换…；坏成品拆解→重装→可能再坏→再拆…——如果策略不当，流程永不终止。

## 二、解法链

| 问 | 方法 | 核心 |
|----|------|------|
| 一 | **序贯抽样** | 抽样检验方案（Wald 序贯分析），不是固定抽 n 件 |
| 二 | 递归期望成本 + 0-1 规划 | 零配件/成品期望成本**几何级数闭式求和** → max E(R)，x∈{0,1}³ |
| 三 | 推广到半成品层 | 半成品也当"可拆零配件"递归 → 工序可无限加深 → max E(R)，x∈{0,1}¹³ |
| 四 | **抽样率校准** | 序贯抽样得"抽样次品率" → **三次回归映射回真实次品率** → 重跑 Q2/Q3 |

## 三、核心可学套路（国二的技术含量在这几点）

### 套路 1：递归成本的"几何级数闭式求和" ★★★
"检出次品→换新→再检测→可能再换…"是无限递归，作者不写循环，而是**用几何级数直接闭合**：

检测零件 i 的期望成本 = pcᵢ + xᵢ·icᵢ + **xᵢ·rᵢ·(pcᵢ+xᵢ·icᵢ)/(1−xᵢ·rᵢ)**

（若 xᵢ=1：以概率 rᵢ 换一件 = 再花 (pc+ic)，再以概率 rᵢ 又换…首项 a=pc+ic、公比 q=xᵢ·rᵢ，和=首项/(1−q)。）
> 套路：**"检测-替换-再检测"类递归期望成本 = 等比数列求和**，一步写出闭式，比写蒙特卡洛循环优雅得多，也是解析模型能写出来的关键。

### 套路 2：用"假设"主动切断递归死循环 ★★
"不检测零件→装出坏成品→拆解→又不检测→再装坏成品→…"会无限循环（作者附 curcle.jpg 示意图）。
对策：**假设 c/e——拆解后的东西强制重检直到合格**，把递归深度封顶。
> 套路：**建模时主动识别"策略导致无限循环"的病态情形，用假设切断**——既是模型的必要约束，也是论文里值得单独说明的点（体现你考虑过病态情况）。

### 套路 3：解析与仿真"双轨互证"（国二真本事）★
readme 给了完整解析期望成本公式；代码却全部用**蒙特卡洛仿真**（10 万次/策略）求平均利润做适应度。
- OO 仿真类 Component/HalfProduct/Product，`check()` 内部递归 `disassemble()`，忠实还原"检测→拆解→重检→重装"过程；
- 与解析互为验证：公式给闭式预期，仿真给随机验证；多案例多策略分布图（箱线图）佐证稳定性。
> 套路：**复杂决策题"解析期望 + 蒙特卡洛仿真"双轨**——解析能讲清结构，仿真能应对更真实/更复杂的规则；两者结果一致 = 模型可信。这正是"模型检验"最扎实的形态（比空泛灵敏度强）。

### 套路 4：二进制 GA 与 PSO 双实现对比
13 个 0-1 变量空间只有 2¹³=8192，**其实完全可枚举**，但作者：
- GA：轮盘赌选择 + 单点交叉(0.8) + 位翻转变异(0.1)，种群 100、20 代；
- PSO：粒子位置∈{0,1}，速度更新后 clip+round 映射回二进制（w=0.7,c1=c2=1.5）；
- 两者都输出收敛曲线与策略表——**用启发式算法当"正确性自检"并与枚举/解析互验**。
> 经验：决策变量少时枚举是金标准；写 GA/PSO 是为了展示算法能力，但**务必用枚举/解析结果核对**，防止启发式漏最优（呼应我失败模式 #6：多策略互证）。

### 套路 5：问题四的"测量值校准"思想 ★★
抽样测到的次品率 ≠ 真实次品率（抽样有漏检/误检）。作者做法：
- 先序贯抽样模拟 → 建立**抽样次品率→真实次品率**的映射；
- 用**三次函数拟合**（cubic_model.pkl）→ 把校准后的次品率重新代回 Q2/Q3 优化。
> 套路：**"测量/抽样得到的是带偏估计，先建校准映射再入模型"**——凡是"数据来自抽样/仪器/传感器"的题都能用（呼应 2025C 的"临床测量 vs 真值"）。

## 四、与国一论文的差距（诚实观察，反而值得学）

1. **无 PDF、无正规论文结构**：只有 readme 思路 + 代码——说明**支撑材料工程化不能替代论文**（评委看不到代码里的巧思）；
2. **假设较"定制化"**：假设 c/e 直接改题面规则（"拆解必重检"），若换成题面不允许就得重推——国一会把这类假设做得更普适/更自洽；
3. **缺乏逐问验证闭环**：代码有收敛图/分布图，但没像国一那样做系统的敏感性、误差、可视化三重验证写作；
4. **序贯抽样(Q1)与主体(Q2-4)衔接**：readme 对 Q1 一笔带过，说明建模重心不平衡。

## 五、可复用模板（补风格库）

1. **递归成本闭合**：检测-替换-重检类成本 = 等比级数闭式求和
2. **病态切断假设**：识别无限循环策略，用假设封顶递归
3. **解析+仿真双轨互证**：公式给结构、仿真给验证，交叉确认
4. **测量值校准**：抽样/仪器读数 → 回归映射回真值 → 再入模型
5. **启发式正确性自检**：枚举(小空间)/解析 与 GA/PSO 结果核对
6. **OO 仿真代码组织**：Component→HalfProduct→Product 类 + check/disassemble/sell 递归方法，直观且与题面一一对应
