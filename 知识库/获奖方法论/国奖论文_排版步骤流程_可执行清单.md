## 二、解决问题步骤（每问"五小步"模板）

1. **建模前提/几何**（最易被忽略，国奖加分）：坐标系选取、刚体定理、重心/转动惯量计算 —— 配**示意图**。
2. **模型建立**：受力分析 → 牛顿第二定律/拉格朗日 → 微分方程（列全约束）→ 明确初值/边界。
3. **模型求解**：点名算法（四阶龙格库塔/遗传算法/频域复幅值/差分进化）→ 给出递推式/伪代码 → Step1 初值 → Step2 转化 → Step3 迭代 → Step4 应用。
4. **结果分析**：数据图（时程/分布/灵敏度）+ 结果表（可复现精度）+ 文字"发现"。
5. **检验**（每题至少一项）：误差（数值 vs 解析，注明窗口/步长）、灵敏度（龙卷风+门控参数）、稳健性（换方法/换设定/换步长）；物理直觉校验（如稳态周期==激励周期）。

## 三、写作流程（全文顺序，一篇到底）

```
摘要（单独一页：四段式逐问"方法+带单位数值" + 关键词，800-900 字）
一、问题重述     背景→装置结构→工作原理→逐问详述
二、问题分析     2.1~2.4 逐问：点难点 + 解决思路（先讲思路再建模）
三、模型假设     4-6 条，每条"内容+依据+影响"，含显式风险说明
四、符号说明     三线表（符号/意义/单位）
五、模型建立与求解  5.1~5.4 每问五小步（见：二）
六、模型分析     6.1 模型检验（误差/物理校验）6.2 结果可靠性（±%扰动偏差图）
七、模型总结     7.1 优点 7.2 缺点（诚实，具体到"忽略哪项→有何偏差"）7.3 推广（把缺点当钩子）
参考文献         GB/T 7714，主题紧扣，8-15 条
附录            代码 / 推导 / 参数表
```

## 四、搭配的"图示体系"（结构图用 GPT-Image-2，数据图用 matplotlib）

- **结构/概念示意（GPT-Image-2，low 档）**：流程图、模型框架图、逻辑框图、关系图、泳道图 —— 提示词见 `知识库\模型工具箱\GPT-Image-2_图示生成与提示词.md`。
- **数据/坐标图（matplotlib，图表库.py）**：时程、功率曲线、3D 功率面/等高线、灵敏度龙卷风、±扰动偏差、分布图。
- **图注一律写"从图看出的发现"**（30-50 字），如"旋转阻尼系数改变对输出功率影响很小，可能缘于纵摇角速度较小"。
