# 老哥·论文获奖六大技巧（视频学习笔记）

> 来源：老哥《算法、编程、写作和获奖指南》第 100 集"获奖技巧总结"（画面抽帧 + 语音转录交叉学习）。
> 关键词触发：获奖技巧 / 摘要 / 排版 / 模型假设 / 流程图 / 改进模型 / 模型检验

## 核心收获

老哥明确：**摘要决定进不进终审，进终审 ≈ 获奖（80%+）**；改进/组合模型 + 模型检验是拉开差距的地方。

## 技巧 1 · 摘要一定要认真写

- 至少花 **5 小时**，反复讨论精修，改 **5-6 遍**才交。
- 评审分初审/终审：初审评委 **3-5 分钟**看摘要；摘要好→进终审，不好→PASS（只能优秀奖）。
- 进终审：大概率至少省三（美赛至少 H 奖），美赛数据 **80% 概率获奖**，国赛类似。
- 结构：**凤头**（整体概括）→**猪肚**（三问环环相扣）→**豹尾**（优缺点+检验+特色）。
- 铁律：语言简练（多一句啰嗦、少一句不清）；**不超 1 页**（推荐 2/3 页）；**无图表**；不建议写公式；别忘了**题目和关键词**。

## 技巧 2 · 论文排版一定要美观

- 论文是参赛队给评委的**唯一评审材料**（附录/支撑材料评委基本不看）→ 排版直接决定印象。
- 格式规范（老哥给的具体值）：
  | 元素 | 字体字号 |
  |------|---------|
  | 论文题目 | 黑体 3 号，居中 |
  | 摘要标题 | 黑体 4 号，居中 |
  | 摘要内容 | 宋体 小4 号 |
  | 关键词 | 黑体 小4 号 |
  | 正文一级标题 | 黑体 4 号，居中 |
  | 正文二级标题 | 黑体 小4 号，居左 |
  | 正文 | 宋体 小4 号 |
  | 数字/字母 | Times New Roman |
- 页边距上下左右 2.5cm；正文 **20 页左右**（不超 25）；**1.5 倍行距**（显干净，内容多才用单倍）。

## 技巧 3 · 模型假设一定要认真对待（评委看重 + 同学忽略）

- 很多国赛评委明确说过：假设是**很看重的点**，也是很多同学忽略的点。
- 假设的意义（引肖华勇《全国大学生数学建模竞赛指南》）：抓主要原则、忽略次要原则、**避免建模过程复杂化、提高建模效率**、使模型更合理化。
- 假设不足 → 模型适用性弱/失败。数量 **5-10 条**。

## 技巧 4 · 问题分析推荐使用流程图

- 评委直接看"模型建立求解"会懵（尤其大公式堆砌）→ 流程图直观展示建模步骤/思路。
- 工具：VISIO 或 WPS 自带的流程图模块。
- **铁律：流程图下方必须有文字说明**——流程图给"直观"，文字给"明确"，切忌只有图没文字。

## 技巧 5 · 推荐使用改进/优化/组合后的模型（核心干货）

- 模型建立是评审最重要的模块之一；但 3 天赛程几乎不可能创造全新模型，多是选已有模型。
- **别直接套用现成模型**（如 BP）→ 给评委"太普通"感，且原模型缺点你没提 → 低分。
- 改进/组合方向（老哥举例）：
  - 评价类：**熵权法 + AHP 组合评价**（定权更准确合理）；
  - 小样本预测：**BP 神经网络优化灰色预测**（灰色擅长小样本 + BP 修正）；
  - 大样本预测：**遗传算法优化 BP**（避免 BP 陷入局部最优）。
- 论文里写清："改进避免了原模型的 XX 缺点，同时发挥了它的 XX 优点"。

## 技巧 6 · 增加模型检验模块（很多同学不写！）

- 评委看到模型检验 = 认为你**建模过程正确**（非主观臆断）→ 说服力↑ → 高分。
- 模型检验 = **误差分析** + **灵敏度分析**：
  - 误差分析：检验模型**正确性**。用一部分数据验证另一部分，看误差大小。主要用于**预测类**题目（预测精度准不准）。
  - 灵敏度分析：检验模型**普适性**。把模型中某定量参数改变，看结果有无大波动；没大波动 = 稳健/普适强；某参数一变结果剧变 = 稳健性弱。用于**含固定参数**的模型。
  - 建议：预测/评价类题目做模型检验+误差分析；模型有固定参数做灵敏度分析。
- **模型优缺点评价是必写环节**（任何题型都要写）。

## 验收题（学习闭环）

> 你在写一篇预测类论文（灰色预测改进模型），距终稿还有 2 小时。
>
> 请回答：① 摘要该占几页、花多久写、什么结构？② 为了"改进模型"的说法成立，论文里必须写清什么？③ 评委认为你"建模正确"靠哪一部分？你要补哪两个检验模块？
