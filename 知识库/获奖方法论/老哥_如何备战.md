# 老哥·如何备战数模比赛（p4 视频学习笔记）

> 来源：老哥 p4「如何备战数模比赛」。

## 一、团队分工及要求

**建模员**（系统掌握各类模型，每类 4 问）：
① 该模型的主要功能？② 适用场景？③ 实现需要哪些条件？④ 缺点/不足、可怎么改进？

**程序员**（Matlab/Python）：
① 编程基础 ② 实现各类常见算法 ③ 能改 Bug ④ **能制作精美图片**

> 建模员 4 问 = 我的知识库每篇条目的骨架（触发词/场景/步骤/坑 = 功能/场景/条件/改进），设计一致 ✓

## 二、备战路径（三阶段九步）

| 阶段 | 步骤 |
|------|------|
| 理论 | 学基础知识 → 学算法 → 学优秀论文 |
| 技术 | 学编程 → 调试常用模型 → **复现优秀论文** |
| 交流 | 掌握写作要求 → 掌握学术语言 → 掌握排版技巧 |

> "复现优秀论文" = 我的评测回路（真题+对标优秀解）。

## 验收题（学习闭环）

> 按"备战路径"对照你的准备：① 理论阶段你做了什么（对应知识库哪部分）；② 技术阶段的"调试常用模型"你验证过几个（8/8 模板真跑）；③ 还差哪一步（写作/排版练习）？
