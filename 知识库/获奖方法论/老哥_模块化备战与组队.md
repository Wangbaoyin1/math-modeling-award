# 老哥·模块化备战与组队（p2 视频学习笔记）

> 来源：老哥 p2「各模块备战及组队策略」。

## 一、数学建模一般步骤（老哥版，呼应我的 M1）

- **模型假设**：针对问题特点、合理简化、**在合理与简化之间折中**（不能太简也不能太繁）。
- **建立模型**：用数学语言描述问题、发挥想象力、**尽量用简单数学工具**（别炫技）。

## 二、模块化备战（逐模块击破）

| 模块 | 备战要点 |
|------|---------|
| 题目 | 掌握固定模式："基于___模型的___研究与分析" |
| 摘要 | 总结归纳能力，看高水平/优秀论文掌握 |
| 问题重述 | **切忌抄题**：描述简短的"拆建"、描述复杂的"精炼" |
| 问题假设 | 明确假设点（见下） |
| 其余 | 建模/求解/检验/评价各自备好模板 |

## 三、假设点的精确定义（补充 M4，很实用）

**什么该设为假设？** 满足其一即可：
1. 对结果有影响、但属**小概率事件**；
2. 对结果有影响、但**难以计算获取**。

> 这给了 M4"假设怎么选"的可操作判据——不是随便列，而是"影响大但小概率/难算"的才设为假设。

## 四、团队关系（实用 + 玩笑）

- 推荐：两男一女（100分）/ 两女一男（90分），理由：建模+编程+写作三岗互补。
- 玩笑：三个男生 60、三个女生 40（纯调侃）。
