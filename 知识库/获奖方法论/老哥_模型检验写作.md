# 老哥·模型检验写作（视频学习笔记）

> 来源：老哥课程 p55「模型检验写作」（24 分钟，画面逐帧学习）。

## 模型检验模块组成

模型检验 = **灵敏度分析 + 统计检验 + 误差分析 + 新旧模型对比 + 稳定性**。评委看到检验 = 认为建模正确（非主观臆断）→ 加分。

## 一、稳定性与灵敏度分析（核心，同一类型）

**定义**：检验模型中某参数变化是否引起模型输出变化。

**写作模板**（完整示例）：
> "死亡率可能会出现一些误差，因此对其进行灵敏度分析，得到不同死亡率下人口总数预测曲线（图 13）。"
> （图：不同参数值 0.001~0.008 下的结果曲线，带图例）
> "从图中可以看出，人口总数对死亡率的灵敏度并不高，因此可以认为用拟合得出的死亡率进行预测是可行的。"
> 分模型逐个做（模型二做死亡率、模型三做男女出生比例……）

**写法要点**：改参数（±x%）→ 画多曲线图 → 结论（"不敏感→模型可行"或"某参数敏感→需精确取值"）。

## 二、统计检验 vs 误差分析

| | 统计检验（假设检验） | 误差分析 |
|---|---|---|
| 内容 | t 检验、F 检验，判断模型准确 | 模型在测试集验证 + 分析误差 |
| 位置 | 主要写在**建模过程中** | 含真实数据→写求解部分；无真实数据→文末做**误差来源分析** |

## 三、误差来源分析（无真实数据时必写，示例三分类）

分析模型的误差来源，每类给影响大小：
1. **离散化误差**：地理坐标离散化 → 最大值 3.45%，可忽略
2. **算法收敛误差**：粒子群易局部最优 → 减少运算量/人为干预
3. **预处理误差**：Hough 变换找平行线的视觉误差

> 写法：每类误差"产生原因 + 影响大小（数值）+ 是否可接受"。

## 四、新旧模型对比

- 场景：原模型无法解答赛题 → 改进使其更贴合 → 新旧对比。
- 位置：模型建立/求解部分（不是检验部分）。
- 对比内容：改进前后效果（量化：精度提升 X%、成本降 Y%）。
