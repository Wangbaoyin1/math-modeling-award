# 高级图（出版级图表规范）

> 用途：论文所有配图（趋势图、对比柱状图、热力图、龙卷风图、示意图）。**图是评委快速理解你工作的第一入口。**
> 来源：内化自 Nature 级图表指南 + 国赛规范，增强 UltraMath《出版级图表规范》。

## 一句话核心

国奖图 = 「**自解释 + 语义配色 + 中文字体正确**」。图的目的是让评委**不看正文也读懂一个结论**——所以每张图必须"自解释"。

## 字体铁律（最易踩的坑）

```python
import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'sans-serif'
plt.rcParams['font.sans-serif'] = ['SimHei', 'Arial', 'DejaVu Sans']  # SimHei 必须第一！
plt.rcParams['axes.unicode_minus'] = False   # 负号正常
```

> ⚠️ **SimHei 放第一**，不是 `['Arial','SimHei']`——否则每个中文字符先在 Arial 上失败，刷屏警告 + 中文变方块。

## Nature 语义色板（配色有语义，不是好看）

| 颜色 | 含义 | 用途 |
|------|------|------|
| 蓝 #0F4D92 | 主方法/最优解 | 突出你的方法 |
| 灰 #CFCECE | 基线/对比 | 衬托 |
| 红 #B64342 | 瓶颈/警告 | 标注问题 |
| 绿 #8BCF8B | 改进增量 | 少量使用 |

> 规则：**一张图一个色板家族**；不用红绿对比（色盲）；不用 jet/rainbow。

## 图注四要素（自解释的关键）

每张图的 caption 必须回答：
1. **是什么**：图类型 + 内容（"收敛曲线"）
2. **怎么做**：关键参数、样本量、方法
3. **看什么**：突出/异常的数值或趋势
4. **说明什么**：一句结论（趋势→归因→决策）

## 排版铁律

- 只保留**左下 spine**（去掉右上边框），无网格线
- `legend.frameon = False`（无框图例）
- 国赛图**必须全中文**（标签/标题/图例/注释），禁止英文标签或中英混排
- 导出 SVG（可编辑）+ PNG 300 DPI，`bbox_inches='tight'`

## 图表类型选择

| 数据特征 | 优先图 |
|---------|-------|
| 少量精确数值 | 三线表 |
| 趋势/连续 | 折线图 |
| 分类对比 | 柱状图 |
| 分布/密度 | 直方图/箱线图 |
| 相关性/聚类 | 散点图 |
| 参数影响排序 | 龙卷风图（敏感性标配） |
