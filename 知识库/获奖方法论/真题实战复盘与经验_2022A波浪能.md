## 第①部分：本题遇到的困难（按环节归类）

### 1. 环境与工具（全自动流程最容易被卡死的地方）
- **无外网**：pip 装不了库 → 只用已装好库（numpy/pandas/scipy/matplotlib/openpyxl）；题目 PDF 无现成提取库 → **手写 PDF 文本提取器**（解析 ToUnicode CMap 的 bfchar/bfrange、CID 字体十六进制文本），成功解出题面与附件 xlsx。
- **LaTeX 编译被沙箱阻断**（最耗时的一段）：
  - xelatex 首次运行要自建 `xelatex.fmt`，而 spawn 子进程（CreatePipe）被禁 → **手动 `miktex-xetex.exe -ini -etex` 建 fmt**；
  - 缺 `zhnumber.sty` → **手写兼容版**（提供 ctex 需要的 \zhnum_counter:n 等）；
  - xelatex 结束时 triggers dvipdfmx 子进程被禁 → **改用两步**：`miktex-xetex.exe '&xelatex' -no-pdf` 产 `.xdv`，再单独 `miktex-dvipdfmx.exe -o xx.pdf xx.xdv`；
  - MiKTeX 二进制对**任何 stdout 管道/重定向都会静默失败**（`|`、`2>&1`、`>file` 全失败，只能直接控制台输出并忍受巨大日志）→ 关键指令给"**直控台跑 + 依赖时间戳/xdv 核验成功**"；
  - MiKTeX 要写 `C:\Users\...\MiKTeX` 被拒 → 设 `MIKTEX_USERDATA/CONFIG/INSTALL` 指到工作区。
- 附件 GIF（动图）视觉没法看（模型不支持图 / vision 读不了 GIF）→ 靠**题面文字 + 物理几何推断**。

### 2. 建模/理解的坑
- **几何方向不确定**：弹簧压缩还是拉伸、振子在铰点上方（倒摆）还是下方——只能靠空间约束（振子半径 0.5m 放不进 0.8m 圆锥）推断为**上方倒摆 + 弹簧压缩**；此假设[强]必须交代"内容/依据/影响"；（后续正是这个"倒摆"引出稳定性门槛洞察，但也是它埋下"设计杠杆越过稳定域"的雷）。
- **幂律阻尼"最优参数"不是单点**：差分进化初报 (99950,0.415)→227.12W，**低于 α=0 线性元下界 229.33W**（族内最优不得低于线性最优）→ 说明**目标函数窗口/周期不足、未收敛**；且"最优"在参数空间是**脊状不可辨识区**（参数不可辨识，须如实披露"脊"而非硬报单点）。
- **稳态平均功率的窗口**：单周期平均随相位/步长抖动（113~133W），需**多周期平均 + 长积分**；纵摇通道是**慢瞬态**（τ≈50s、约 14 周期），40 周期包络未收敛（过报~8%）→ **稳态值改用频域解析真值**，并注明"40 周期时程是题目要求的含瞬态响应"。

### 3. 结果口径 / 独立验证
- 自己算的"误差<1%"用单点示例（230.1W）**不可复现** → 改 200 周期长程积分复算（229.334W vs 解析 229.3339，0.0004%）并按**量域**限定（垂荡/功率<0.5%、纵摇<1%）。
- 独立验算员（不同方法：solve_ivp 长积分 vs 自制 RK4、频域闭式 vs 数值、网格 vs 进化）**抓到"数值自洽但物理/口径错误"**：215 个 Q2(2) 227.12<229.33 下界、Q4 c_r 不可辨识。
- **三席盲评（A/B/C 不同权重、不告知目标档）最具价值一击**：B 席位用**特征值稳定性复核**揪出"设计杠杆 +5.4%@k_t=3e3 位于**静力不稳定域**"——因为 K[4,4]=k_t−m_o·g·s_eq（倒摆项 4815 N·m）当 k_t<1.05e4 时 K 不正定（Re λ>0，屈曲发散）→ "+5.4% 是数学特解、物理不可达"，修正为"**k_t 须高于静力稳定门槛 1.05e4 N·m，稳定带内纵摇分支收益上限仅 +2%**"。

### 4. 论文 / 审稿（首轮被指出的硬伤，全部修复复验）
- 图4 注记 227.1W 与正文/摘要 229.99W **矛盾**、色标上限<峰值；矩阵"见附录推导"但**全文无附录**；表2 "x_o" 列符号与正文定义冲突；摘要 600 字 **<800**；Q3 幅值取 40T 包络**过报 8%**；"宽高原"矩形边界**夸大**（角点 214.7W）；"误差 230.1W"**不可复现**；灵敏度**未扰门控参数** k_t/ω；洞察**缺可行动杠杆**；k_t 单位未标 **/rad**；**M[0,0] 纸面漏 m_o**（按公式重建会差 52%）；c_r 平坦区间\[1e3,2e5] 实测 0.123W 与"<0.05W"不符（应为\[6e4,2e5]）。
- **官方优秀论文对比**：我方 Q1/Q2(1)/Q2(2)/Q4 与官方**高度一致**（Q2(2) 参数不同但同落"脊"、Pmax 226→230 一致；Q4 官方也确认"旋转阻尼影响很小、可能纵摇角速度小"——与我"旋转仅 0.14W 平坦平台"完全一致）；但官方 Q3 **忽略纵摇-垂荡耦合**（假设3）且 I_f=8289.43（分壳分解），我方完整 4 坐标耦合 + I_f=5593.9（实心），纵摇我方更小——**我方完整耦合更合理**（官方分离模型高估纵摇），值得在论文说明。

### 5. 可视化欠缺（本轮最痛的教训）
建模全程**没有任何物理示意图/受力图/分布图**，是相对官方优秀论文最大的**结构性差距**；官方有"坐标系示意 / 受力分析示意(左右两图) / 重心分解 / 3D 功率曲面 / ±1% 扰动偏差双面板 / 方法示意(梯形积分) / 发现性图注"——**这些我方可直接借鉴为本轮高频加分项**。

## 第②部分：可迁移经验 / 方法论增量（下一题默认执行）

### A. 环境自检与降级策略（开始前先探测）
1. 确认 `numpy/matplotlib/scipy/openpyxl` 可用；无外网则用内置库，不依赖 pip。
2. PDF 无库 → 手写提取（zlib 解流 + ToUnicode CMap + CID 文本）；附件表格用 openpyxl/pandas 直读。
3. LaTeX 在沙箱下：**探测 xelatex** → 若 mtk 自建 fmt、缺宏包则手写兼容（zhnumber.sty）+ **两步编译**（`-no-pdf` 产 xdv → 单独 dvipdfmx）→ **MiKTeX 环境变量重定向用户数据目录到工作区** → **避免对 MiKTeX 用管道/重定向**（只直控台 + 看 xdv/pdf 时间戳核验）。
4. 初始就固定 `np.random.seed(42)`，保证可复现。

### B. 机理建模（必先可视化，再进公式）
1. **每问建模前先画"坐标/受力/几何"示意图**（左右两图：整体+剖面），写进论文（否则评委第一眼看不懂、也远低于国奖水准）。
2. 自由度/核心量 ≤3，全文贯穿；每个[强]/[弱]假设给"**内容+依据+影响**"三件套，数量 4-6 条，并做"假设-检验映射"。
3. 正问题用数值积分；反问题优先**频域/解析映射**（快+准），非线性用**长程数值稳态 + 多周期平均**；给"方法选型理由 + 1 备选"。

### C. 优化/反问题（易踩的坑）
1. **核查"最优点是否单点可辨识"**：不可辨识（脊/高原/平坦）→ 如实报"不可辨识区 + 峰值区间"，勿硬报单点。
2. **用"退化/下界"自检**：若族内含特例（如幂律 α→0=线性），则族内最优**不得低于该特例**；若你的最优低于它，说明目标/窗口未收敛。
3. 稳态平均先做**窗口/周期稳健性**（多周期平均、长积分、步长减半、周期加密）；慢瞬态通道用**频域真稳态**并注明"时程=含瞬态响应"。
4. **多参数优化加"物理可达性/稳定性"检查**：特征值判 K 正定/动态稳定；排除"不稳定域/屈曲域的数学特解"，把稳定性门槛本身作为**设计约束/洞察**（很有价值）。

### D. 独立验算（信息隔离、不同方法）
1. 验算员**不读推导/不看主代码**，用不同类型方法（不同 ODE 求解器、频域 vs 数值、网格 vs 进化）复算；优先级：先核**数值一致性**，再核**物理/口径合理性**（能抓"自洽但错误"）。
2. 验算要覆盖"最优参数可辨识性、下界/退化、稳定性、收敛口径"。

### E. 审稿（三席独立盲评，每席不同权重、不告知目标档）
1. 每席给 YAML scorecard（criteria 权重和=1、0-100、weighted_total、implied_tier），主控聚合：三席 tier 都≥目标、weighted 达标、无单维跌破 floor。
2. 重点抓**内部不一致**（数值-正文矛盾、图文矛盾、公式-代码不一致）、**不可复现**（无窗口/步长/种子）、**物理不可达**（不稳定域当最优）、**缺失项**（矩阵"见附录"但无附录、缺检验/门控扰动、缺可行动杠杆）。
3. 修复后**带证据复验**（outlier 席位复核），Phase 4 最多 2 轮重评。

### F. 论文规范（对照国奖优秀论文）
1. **摘要**：逐问"方法+带单位数值"、单独一页 800-900 字、四段式、无图表、少套话。
2. **图示体系**（国奖标配，本轮教训重点）：
   - 示意图：坐标系/受力分析（左右两图）/重心分解/定理示意；
   - 分布图：**3D 曲面**（能直观看"哪个参数方向灵敏、哪个方向平坦"）+ **±1~10% 参数扰动偏差双面板**；
   - 方法示意图（数值积分/算法流程）；
   - **图注写"从图看出的发现"**（30-50 字），非只描述。
3. **表格**：结果表给**可复现精度**；三线表；参数取值表（m_a/c_w/ω/f/L 等一表）。
4. **检验三件套**：误差（数值 vs 解析，注明窗口/步长/量域）、灵敏度（龙卷风 + 相对灵敏度系数 + 结论门控参数扰动，如 k_t/ω）、稳健性（换求解方法/换模型设定/换步长，结论不翻转）。
5. **机理强化**：补"物理直觉校验法"（如稳态周期==激励周期、能量守恒、量纲一致）与"频率串联/整机趋势"讨论；缺点的**诚实披露**（忽略哪项→有何偏差→作为推广方向）。
6. **AI 合规**：参考文献前放「AI 工具使用声明」（未用或用了+用途），用了则附支撑材料（如《AI工具使用详情.pdf》），核心建模由"参赛队"主导并逐一人工核验。

### G. 与官方/优秀论文对比（做完必做，验证+找差距）
1. 先对齐**结果一致性**（若同题有官方/高分解，验证我方数值是否正确：官方优秀论文 Q1/Q2/Q4 与本解几乎一致）。
2. 再对齐**图示/论证/检验**差距，吸收"周期校验法 / 3D 分布 / ±1% 扰动图 / 发现性图注 / 分壳分解 vs 实心"。
3. 我方相对官方的**优势**（深度、稳定性、完整耦合、检验体系）要在论文明说，别只露不足。
