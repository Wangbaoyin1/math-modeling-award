# 老哥·国一建模全流程（p109 赛题解析）

> 来源：老哥 p109「国一选手建模全流程」，以 2019 C 机场出租车为示范。
> 关键词触发：读题 / 定位题目 / 全流程

## 一、如何真正读懂和定位题目（最关键的第一步）

把赛题提炼为 **输入 → 约束 → 输出** 三要素：

> 以 19C 机场出租车为例：
> - **输入**：机场乘客和司机数据（附件）
> - **约束**：排队规则 + 车辆/乘客安全
> - **输出**：最优上车点 + 上车方式

**方法**：读题时逐句找"给了什么数据（输入）、要满足什么条件（约束）、最后要给出什么（输出）"——答非所问的根因就是没定位清楚输出。

## 二、"三次思路"策略

解题过程中对思路要**持续改动完善**，不是一次定死：
1. **找资料**（先查有没有现成方法/类似题）
2. **开拓思路**（主要：发散，多角度想）
3. **考虑时间精力取舍**（3 天赛程，会取舍：难题保底、能做的做深）

## 三、赛题常见解法链条（从 19C 看）

1. 问题一（评价）：建"出租车司机决策评价指标体系"→ 评价"蓄车"模式 → 给判断理由
2. 问题二（收益+合理性）：载客收益建模 → 分析模型合理性
3. 问题三（优化）：单/多目标优化模型 → 效果和指标评价
4. 问题四（定价）：总收益最高定价方案

> 一套题 = 评价 + 机理/收益 + 优化 + 决策，四问递进（呼应"由简到繁"）。

## 验收题（学习闭环）

> 用"输入→约束→输出"给 2023C 蔬菜定价题做一次定位：① 输入数据是什么？② 有哪些约束？③ 每问的输出是什么？④ 你会怎么安排"三次思路"（先找什么资料）？
