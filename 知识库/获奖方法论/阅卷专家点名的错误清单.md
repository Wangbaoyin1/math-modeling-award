# 阅卷专家点名的错误清单（韩中庚·2015B评析）

> 来源：韩中庚（阅卷组权威）《"互联网+"时代的出租车资源配置问题评析》第4节"参赛论文中存在的问题"。
> 定位：**评委亲口说的、最反感的8类错误**——比任何经验帖都权威。明天做题**逐条避开**。
> 用法：Phase 0 定框架时扫一遍、Phase 1 建模时扫一遍、Phase 3 写论文时扫一遍。

---

## 一、评委点名的 8 类致命问题（逐条避开）

### ① 没抓住题目的核心问题 → 所答非所问
- 原文：很多参赛队"对问题本身的理解不够深刻，没有抓住该题目的核心问题"，结果"所讨论的问题似乎都是一些无关紧要、不大相干的内容，完全偏离了题目所要求研究的主要问题"。
- **教训**：Phase 0 必须**逐句解析、抓住题目核心矛盾**（本题核心=「互联网+」+「缓解打车难」这两个核心）。抓不住核心，写得再多也白搭。

### ② 对概念作狭义理解 → 把动态问题做成静态
- 原文：把"不同时空"的"时"理解成"不同年份"、"空"理解成"不同省份" → "完全变成了一个静态的问题"，"这不是这个题目要研究的问题"。
- **教训**：**概念要按题目本意理解**（时空=一天内的时段×城区），别偷换成人省事的宏观统计。

### ③ 盲目"抄、搬、套"文献 → 过犹不及
- 原文："很多参赛队非常热衷于现有的文献结果，但又缺乏甄别判断的能力，也就出现了不少盲目'抄、搬、套'文献的现象……凡是过度'抄、搬、套'现有文献的论文都不会是好的论文。"
- **教训**：文献要"**用**"不要"**抄**"（见 `阅卷标准与写作禁忌_权威版.md`）；沾边就套只会露怯。

### ④ 只知方法、不知适用性 → 方法罗列堆积
- 原文："一些参赛队似乎只是了解一些常用的数学建模方法，但不清楚这些方法的适用性和实用性，即只知道其然，而不知其所以然……表现为一些常用建模方法的简单罗列和堆积，不知道是用来做什么的，要解决什么问题……**似乎是会什么方法就写什么方法，甚至学了什么模型就写什么模型，相关的、不相关的都写上**。"
- **教训**：**先分析问题结构 → 再选方法**（而非先想展示什么方法）。每个方法必须回答"它解决本题的什么问题"。

### ⑤ 为用而用、凑内容抄公式 → 方法牵强
- 原文："有些方法用在这里是很牵强的，给人的感觉就是**为了用而用，或是为了凑内容、抄公式**，没有针对具体问题来解决问题。"
- **教训**：宁少勿滥。**一个用得恰当的方法 > 三个牵强的方法**。

### ⑥ ★八股定式（最该警惕，评委直言"数学建模八股文模式"）
> 原文："现在似乎形成了一个习惯定式，**只要问题中含有'指标''综合''评价''合理性'等词语，无论什么问题，都是层次分析、模糊评价、神经网络等；只要有计算求解的问题，无论简单与复杂，都是遗传算法、神经网络、模拟退火等；只要有'预测'二字，无论样本数据如何，都是灰色系统、时间序列等；只要有数据分析，无论什么样的数据，都是多元统计回归等，似乎成了数学建模竞赛的八股文模式**。诸如此类，都是不正常的数学建模思维方法。"
- **教训（铁律）**：**绝不按"关键词→方法"的定式套模板**。看到"评价"不要条件反射上 AHP/熵权/TOPSIS；看到"预测"不要条件反射上灰色/时序。**要根据问题的实质结构选方法**，哪怕是最简单的（"最简单的或许就是最好的"）。
- 反面案例：出租车题问1要"建立合理性指标分析供求匹配"，很多队却套 AHP/模糊综合评价/熵权/TOPSIS/神经网络——**评委认为"不属于该问题所研究的内容"、"不是一种好方法"**（原文明确否定）。

### ⑦ 把各问当独立问题简单回答 → 缺系统性与连贯性
- 原文："有不少论文将这３个问题当作独立的、不相关的问题做简单回答式的解答，问什么就答什么，没有作为一个实际问题来研究解决，从而使得论文像是分别回答了３个不同问题的答卷，不像一篇围绕一个实际问题的研究论文，缺少系统性和连贯性。"
- **教训**：问题之间是**递进关系**（问题2建立在问题1上、问题3在1和2基础上扩展）。论文要**围绕一条主线**，前后呼应、逐层深入。

### ⑧ 用错方法/牵强套用 → 荒唐
- 原文：出租车司机与乘客、"滴滴"与"快的"之间"都是利益共同体，是相互依存的关系，没有相互对立和竞争的条件，**何来的博弈**？"此类论文似乎都是受到了某些不规范的劣质文献的影响。"
- **教训**：用方法前**先检查前提假设是否成立**（博弈要求"对立/竞争"关系；没有这个前提就不能用博弈论）。

## 二、正向要点（评委希望你做到）

1. **抓住核心问题**，所有内容围绕它展开（别写无关内容）。
2. **要有真实数据支持**（本题评委强调"必须收集某地区或城市的真实数据"，微观数据>宏观统计）。做题时若题目给数据就充分用；若需自找，说明数据来源与合理性。
3. **方法服务于问题**：先讲清"为什么用这个模型、它对本问题的优势"，再建模。
4. **递进式结构**：问1→问2→问3 是"承上启下/进一步扩展"，不是三个独立答卷。
5. **结果要有检验**（数据分析验证或仿真验证），说明结论正确性。
6. 评委明确说：**允许不同方法/不同结论，但要有充分合理的论证**；"结论是什么并不重要，重要的是看建立了什么样的模型、论述是否合理"。
