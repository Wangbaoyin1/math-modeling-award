# 国一论文拆解（以 2023 国一 A·定日镜场为例）

> 来源：逐页精读 2023 全国一等奖论文《定日镜场优化设计模型》（60 页，含附录代码）。
> 用途：知道"国一论文长什么样"，写论文时逐项对标。

## 一、摘要（国一模板，最重要）

**结构公式**：核心思想句 → 总方法句 → 逐问（问题X：方法 + **具体数值带单位**）→ 关键词。

> 示例（国一原文结构）：
> "定日镜场的优化设计对实现高效的太阳能光热转换至关重要。**本文基于蒙特卡洛光线追踪法**，建立了……计算模型……求解出了……"
> "针对问题一：本文建立了……模型。首先……其次……最后……计算出**年均光学效率 61.58%、年均热输出功率 37.629MW、单位面积功率 0.599 kW/m²**"
> "针对问题二：……得到最大……为**0.591 kW/m²**"
> "针对问题三：……得到……为**0.594 kW/m²**"
> "关键词：蒙特卡洛光线追迹法 双层规划 定日镜场布局优化 光学功率"

**国一摘要三特征**：① 首句有核心思想；② 每问有方法名；③ **每问有 1-3 个带单位的具体数值**（评委员就靠这个判断工作量）。

## 二、正文结构（8 段标准）

| 章节 | 内容要点 |
|------|---------|
| 问题重述 | 1.1 背景分析（自绘示意图）+ 1.2 问题提出（用自己的话） |
| 问题分析 | **逐问分析**（为什么用这个模型，不直接抄题） |
| 模型假设 | 6 条具体假设（本文：光锥二维正态分布、半角4.65mrad、同心圆分布等）——具体可检验，非废话 |
| 符号约定 | 表格：参数/说明/单位（规范三列） |
| 模型建立与求解 | 分节 5.1/5.2/5.3（逐问），每问内再分子模型 |
| 模型检验 | 效率分解验证、数值合理性 |
| 评价与推广 | 优缺点 + 适用推广 |
| 附录 | 完整可运行代码 |

## 三、国一建模方法论特征（学到的干货）

1. **复杂问题分解建模**：把光学效率拆成 余弦效率 × 阴影遮挡效率 × 截断效率 × 反射效率（等），**逐项建模再合成**。不是"一个模型到底"，而是"分解-分治-合成"。
2. **公式规范化**：每条公式编号 (5-13)(5-14)，紧跟"其中，η_ref 为常数取 0.92，其他效率见 5.1.2-5.1.5 节"——变量说明 + 交叉引用。
3. **物理量有出处**：DNI 表达式"其表达式为[6]"——物理公式引用文献，增强可信度。
4. **布局建模用对称性降维**：假设同心圆密排（假设 5、6）→ 参数从"每个镜子"降为"每圈镜子"→ 计算量大减。
5. **图辅助理解**：定日镜场示意图、截断效率示意图等（配合文字）。
6. **优化用双层规划 + 控制变量**：把"吸收塔位置+镜子参数"的多参数优化拆成"上层定塔位→下层定镜参数→反馈迭代"，控制变量遍历。
