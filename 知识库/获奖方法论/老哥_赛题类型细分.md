# 老哥·赛题类型细分（p5 视频学习笔记）

> 来源：老哥 p5「赛题类型」，补充 p98 的三大类笔记。

## 预测类五种细分（选方法依据）

| 类型 | 例子 | 常用方法 |
|------|------|---------|
| 小样本内部预测 | 插值/拟合已有范围 | 插值、拟合 |
| 大样本内部预测 | 补全数据内部规律 | 统计/回归 |
| 小样本未来预测 | 少数据外推 | 灰色预测 GM(1,1) |
| 大样本 + 随机/周期未来预测 | 有波动周期的未来 | 时间序列(ARIMA/季节) |
| 大样本未来预测 | 数据多推未来 | 回归/神经网络 |

## 评价类（补充案例）

- 信息/商品评价（2012A）、文本评价（红楼梦作者之争）——评价 = 建指标体系 + 定权重 + 排序。

## 优化类三要素（缺一不可）

**目标函数 + 决策变量 + 约束条件**（老哥反复强调，和我工具箱 T1 一致）。

> 给"未来 7 天蔬菜销量预测"归类：属哪种预测细分？选什么方法？（数据 1000 天、有周末周期）
