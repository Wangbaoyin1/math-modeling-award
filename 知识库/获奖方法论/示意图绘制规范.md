# 示意图绘制规范（让老师眼前一亮的图）

> 核心认知：**评委翻论文第一眼看到的是图，不是公式。** 图分三类，缺一不可——只会画"数据图"的队伍一眼就被看穿"没深度"。

## 一、三类图的定位（先分清再画）

| 类型 | 作用 | 画图工具 | 我们现在的状态 |
|---|---|---|---|
| **① 数据图** | 展示结果数值（趋势/对比/分布/空间） | matplotlib | ✅ 已 20 款（含 6 高级可视化） |
| **② 分析图** | 展示"你做了深入分析"（验证/敏感/收敛/权衡） | matplotlib | ✅ 已补 5 款（Pareto/预测vs真实/特征重要性/收敛/预测区间） |
| **③ 示意图** | 展示"你的模型长什么样、怎么想的"（结构/机理/流程/路线） | **draw.io / PPT / TikZ** | ❌ 完全空白 ← 本次补齐 |

> 一句话记忆：**数据图给结果、分析图给洞察、示意图给门面。** 门面（示意图）决定评委对你的第一印象。

## 二、示意图的四类（必须会的）

### 1. 技术路线图（整体框架，论文最亮眼的一张）
- **放哪**：摘要之后、正文第一张图。
- **画什么**：问题 → 数据/机理 → 模型 → 算法 → 验证 → 结论 的完整链路，用分栏 + 箭头串联。
- **创新点写法**：每个模块右下角用**小字标注该模块的创新点**（如"对称降维""两阶段筛选"），让评委 30 秒看懂你的全部亮点。

### 2. 模型结构 / 系统框图
- **画什么**：模型的组成模块（变量、约束、目标、子模型）及相互关系。
- **关键**：模块用圆角矩形、关系用带箭头连线、**变量符号要标在连线上**（如"价格 p → 需求 D"）。

### 3. 算法流程图
- **画什么**：求解步骤（输入 → 判断 → 循环 → 输出）。
- **标准符号**：圆角矩形=处理步骤、菱形=判断分支、平行四边形=输入输出。
- **关键**：把**迭代/收敛**画出来（循环箭头 + "否→回到第2步"），比平铺步骤更显功力。

### 4. 机理 / 场景示意图（题目场景复现）
- **画什么**：题目的物理/几何场景，**坐标系 + 参数符号 + 几何关系全部显式标注**。
- **关键**：这是评委判断"你有没有真正理解题目"的窗口。图上的每个符号必须与公式里的符号一一对应。

## 三、工具选型（按优先级）

| 工具 | 适用 | 导出 | 推荐度 |
|---|---|---|---|
| **GPT-Image-2（AI 生成）** | 结构性示意：流程图/框架图/逻辑框图/泳道图 | PNG 1024×1024 | ⭐⭐⭐ 首选（学术黑白+中文+含公式，见 `模型工具箱/GPT-Image-2_图示生成与提示词.md`） |
| **draw.io / diagrams.net** | 几何/装置示意图、需精确标注的框图 | 300dpi PNG | ⭐⭐⭐（精确可控、矢量） |
| **PPT** | 手边最快的框图 | 导出高清 PNG | ⭐⭐ 应急 |
| **TikZ（LaTeX 内嵌）** | 最专业的矢量图 | 直接进 PDF | ⭐⭐⭐ 论文级首选（cumcmthesis 支持 `\usepackage{tikz}`） |
| **Graphviz/DOT** | 程序化画复杂流程图 | PNG/SVG | ⭐ 代码控 |

> **铁律：示意图必须是矢量图，禁止用 matplotlib 硬凑示意图。** matplotlib 只负责数据图+分析图。

## 四、创新点设计思路（核心，背下来）

1. **技术路线图分栏配色**：数据准备(蓝) → 建模(橙) → 求解(绿) → 验证(灰)，颜色与数据图统一用 Paul Tol 色板。
2. **每张示意图配一句话图注**：图注不只写标题，要写"这张图在讲什么结论"（如"图1 本文技术路线：先…再…，创新点见红框"）。
3. **机理图标全符号**：坐标系、参数、几何关系一个不漏——符号与公式一一对应是专业度的硬指标。
4. **流程图带循环**：画出迭代/收敛回路，比平铺步骤高一个档次。
5. **路线图圈创新**：用红框/加粗标出"本文创新"的模块，让评委不用找。

## 五、国奖论文的示意图范例（照抄结构）

| 题 | 示意图怎么画的 | 可抄的点 |
|---|---|---|
| 2023A 定日镜 | 镜场同心圆密排 + 塔位 + 反射光线标注 | 场景图 + 参数符号全标 |
| 2024A 板凳龙 | 龙头 + 223 节链节 + 碰撞判据几何标注 | 机理图 + 判据可视化 |
| 2025A 烟幕 | 目标圆柱表面采样点 + 遮蔽区域剖面 | 判据图（把"严格全遮"画成图） |
| 2023B 多波束 | 测船轨迹 + 覆盖带 + 重叠率标注 | 场景图 + 核心变量标注 |

## 六、落地铁律（Phase2/3 强制执行）

1. **全局 1 张技术路线图**：Phase2 开始就画，放论文第一张。
2. **每问 ≥1 张机理/流程图**：说明"这一问怎么建模、怎么求解"。
3. **示意图一律矢量**：draw.io 导出 300dpi PNG，或 TikZ 内嵌；不得用 matplotlib 拼示意。
4. **图注规范**：`图 X 标题 + 一句话说明结论`。
5. **配色统一**：示意图与数据图同一套色板（Paul Tol）。

## 七、自检清单（交论文前逐项打勾）

- [ ] 有全局技术路线图（放正文第一张）
- [ ] 每问至少 1 张示意图（机理/流程/结构）
- [ ] 数据图用了 ≥1 张高级可视化（雷达/小提琴/桑基/和弦/脊线/气泡）
- [ ] 分析图齐全（验证图 + 敏感性龙卷风 + 收敛/Pareto）
- [ ] 所有图符号与公式一致、无缺字（中文 SimHei、R² 用 `$R^2$`）
- [ ] 每张图配一句话图注
