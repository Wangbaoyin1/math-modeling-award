# 高级图表库参考指南（★战时可调用的"加分视觉范式库"）

> 定位：比赛写论文时，**按范式取用**给模型/结果配上"审稿人眼前一亮"的高阶图。
> 来源：素材库 `高级图\`（45 张，知乎"阿昆的科研日常"等科研绘图博主）。
> 用法：先看下方范式总表 → 按你的题选 1-2 个范式 → 本节"复现要点"用 matplotlib/Python 复刻。
> 原则：**绝不直接贴别人的图**——图片是范式参考，我用代码复刻同款效果做你的题，并可在此基础上做创新。

---

## 一、为什么这批图能加分

数模国奖论文的图，**打动审稿人的不是"画得花"，而是两点**：
1. **信息密度**——一张图同时传达"模型结构 / 参数关系 / 结果规律"三样东西；
2. **专业感**——配色统一、坐标标注规范、有阴影/参考线/inset 等"科研级"细节。

高级图 = 基础图（柱/线/散点）**升级**而来的形态。下表把这 45 张归纳成 14 个范式，并标注「对应国赛审稿最爱看的类型」。

## 三、比赛怎么选（决策树）

```
你的题是哪类？
├─ 有"构建模型/整体流程" → 必放 A1 框架图（每篇都要）
├─ 有"多目标/参数优化" → 必放 B1 能量面 + B4 收敛图（冲国一）
├─ 有"场地/位置/覆盖" → 必放 E1 地理覆盖图（EOC 范式）
├─ 有"精度/拟合" → 必放 F1 inset + F2 预测vs实测
├─ 有"多指标评价/对比" → 放 D4 雷达/正负柱 + D1 山脊
└─ 有"关系/聚类" → 放 C1 网络 + C2 相关热图
```

**硬性提醒**：A1 框架图 + F2 精度图 + 某一张"亮点图"（B1/E1/F1 任选）≈ 论文图表的最低竞争力配置，配齐才够国二，配上 B1/E1 这类"求解过程可视化"才是冲国一的差距。

## 四、通用复现要点（用 matplotlib 落地）

每款图都能用 Python 复刻。通用要点：
- **配色**：一套统一色板（如 `viridis`/`cividis` 连续、`Set2`/`tab10` 离散），全书统一，别一图一色。
- **dpi**：`dpi=300`、`bbox_inches='tight'`，避免贴到论文里发虚。
- **坐标**：轴标签+单位齐全、刻度合适、必要时对数轴。
- **标注**：关键值/曲线/区域用文字或箭头标出，信息密度高。
- **inset**：`mpl_toolkits.axes_grid1.inset_locator.inset_axes` 画局部放大。

需要哪款时，我按上面范式直接给你写对应复刻代码（结合你的题数据），并在其基础上做创新（例：B1 能量面上叠加**你的最优解路径**，E1 覆盖图上叠加**你的算法调度**），让它不只是"像那款图"，而是"专属于你的题"。

## 五、创新方向（比素材更好）

1. **图里带结论**：不画干巴巴的场，而是在能量面上**标出最优解/收敛路径**，一图说明"我找到了最优且过程清晰"。
2. **多源叠加**：地理覆盖图上叠加**多时段/多方案对比**（不同方案用不同色覆盖圈）。
3. **三维+投影**：3D 图都加底座投影，信息量翻倍。
4. **动画帧/多面板**：多时序用多面板（如 6 面板面积图），避免单图过挤。
5. **把"求解过程"当主角**：审稿人更想看"你**怎么**解出最优"，B1/B4/E1 就是干这个的——这是内容创新度（#23）在"图"上的落点。
