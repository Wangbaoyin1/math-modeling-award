# 老哥·摘要写作全讲（视频学习笔记）· v2

> 来源：老哥课程 p49「摘要写作规范」+ 2026 国赛摘要硬规范 + **评委批判视角（摘要=第一眼）**。
> 关键词触发：摘要 / 写作规范 / 凤头猪肚豹尾

## 摘要的本质（第一眼 = 生死线）

摘要是独立、有代表性的导读：**不读全文就能获得必要信息**。评委初审 3-5 分钟只看摘要——**摘要决定整篇论文的起评分，是进终审的通行证，也是淘汰赛的第一刀**。

## 摘要 6 大必含要素

1. **背景和问题**：研究对象、内容、目的
2. **问题分析**：依据题目数据/自行收集的信息
3. **关键假设**：基于什么问题/现象/原理提出什么假设
4. **模型结构**：用了什么建模方法、建了什么模型
5. **求解算法**：用什么方法/算法/软件求解
6. **结果、检验、结论**：主要结果 + 对模型/结果的验证

## 四段式结构

```
简述问题 → 建模思路 → 模型求解 → 结果分析
```

### 第一部分 · 摘要前言（2-3 句话）
总结概括：背景/意义 + 研究思路方法 + 成果。三块可全含或含两块。
> 句式："针对……问题/背景，本文基于……方法，建立了……模型，解决了……"

### 建模思路部分
对问题的分析、数据的获取与处理、采用的数学方法、建立的模型。
（老哥示例：基于热传导方程建立温度场模型 / 建立信贷风险评估预测模型）

### 模型求解部分（必写具体！）
**用了什么数据 + 什么方法/软件/平台求解**。
> "利用 MATLAB 编写主成分分析程序，计算出 123 家企业的信贷安全指标"
> "利用差分法对方程组迭代求解，基于最小二乘拟合实测温度，遍历得最优参数组合"

### 结果分析部分
用模型计算结果**回答题目问题**。
- **计算性问题**（物理数学类）：结果正确性直接决定论文质量 → **给出所有要求的量，字体加深、放明显位置**（如"剩余资金为 [0470, 1739] 元"、"成功率为 84.55%，成本节约 5.58%"）
- **开放性问题**：给出方案 + 论证

### 第三部分 · 摘要结尾（总结升华）
优缺点评价 + **创新性评价** + 模型推广。学到的加分句式：
- "本文的亮点在于：首先，利用统一的公式……使模型具有鲁棒性；其次……；最后……"
- "对模型的普适性和灵敏度进行了检验，发现模型具有较好的鲁棒性"
- "该模型可推广到……具有重要应用价值"

## ⭐ 评委第一眼的批判标准（摘要最容易被打回的地方）

> 评委用批判眼光看摘要，第一眼就在挑这些刺。**每一条都是淘汰点**：

| # | 批判点 | 淘汰原因 |
|---|--------|---------|
| 1 | **没给量化结果** | 只有"模型较好/效果显著"，没有数字 → 评委判定"没做出来" |
| 2 | **结果无单位** | 数字不带单位，评委无法判断量级是否合理 |
| 3 | **每问没对应** | 摘要没覆盖题目**所有小问** → 漏问 = 硬伤 |
| 4 | **模型名空泛** | 只说"神经网络"不说"BP神经网络"，或只说"优化模型"不说"多目标整数规划" |
| 5 | **字数超/缺** | 官方 800-1000 字，超了被扣、少了显得没内容 |
| 6 | **跨页/有图** | 摘要必须单独一页、无图表 |
| 7 | **AI 味** | 套话堆砌、模板化"针对XX问题本文提出XX"、无个性 |
| 8 | **结论=空话** | "具有重要应用价值"却不点明价值在哪、推广到哪 |

## ⭐ 摘要的"每问一答"核对法（防漏问）

写完摘要后，**逐问打钩**：题目问了几问，摘要是否每问都有"方法 + 数值"一一对应？缺一问就是漏题硬伤。这是摘要自查的最高优先级。

## 摘要鉴赏（2 篇范文结构）

> "针对……难以直接测量的问题，**提出**了一种……模型。**首先**……；**然后**，采用……求解；**最后**，利用……优化。**实验结果表明**……精度较高，为……提供了理论依据。"
> 关键词：方法 + 领域词（5-6 个）

## 与 p100 六大技巧呼应

- 摘要 ≤ 1 页（推荐 2/3 页）· 无图表 · 题目和关键词必写
- 每问有方法名 + **带单位数值**
- 结构 = 凤头（前言）猪肚（建模求解）豹尾（结尾升华）

## 验收题（学习闭环）

> 用"四段式"给这道题写摘要骨架："某快递站优化配送路线，考虑时间窗和车辆容量，求最小总成本的配送方案"。
>
> 请写：① 前言 2 句；② 建模思路句（方法名）；③ 求解句（软件/算法）；④ 结果句（要有什么数值才够）；⑤ 结尾升华句。
>
> 加考：用"评委批判视角"核对——你的摘要有没有"量化结果+单位+每问对应+模型名具体"四个硬点？
