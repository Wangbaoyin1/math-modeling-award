## 维度 1 · 建模的创造性思维

- **问题重构**：以 FY00 为圆心建**极坐标**，按发射机/接收机相对角度 θi/θj/θk 的关系**分类讨论**——不是照抄题面。
- **核心量**：极坐标 (ρ,θ)、方向角 αi/αj、**间隔数 n**（判编号用）——贯穿四问。
- **创新落点（本题真正难点=编号未知+位置偏差下的调整）**：
  1. **几何分类讨论 + 对称归并**（Q1(1)）：按 θi/θj/θk 次序分 3 类×3 形态=9 形态，再"类别①③旋转对称"归并，只建 **6 个**正弦定理解析模型 → 从"一个通式"到"分类解析"，工程严谨、自然产生多张几何示意图；
  2. **题目转化：定位→先判编号**（Q1(2)）：用"间隔数 n"（n=(180−2α′)/40−1，n=0,1,2,3↔α′=70°,50°,30°,10°）把"编号未知"变成可手算的反推，再用**镜像消除**处理圆对称的"镜像机干扰"；
  3. **三步分层调整**（Q1(3)）：先调 3 架参考机(FY02/FY05/FY08)成理想位→以它们作发射机调其余角度 θk→再以它们为参照调长度 ρk，每步独立模型；
  4. **队形归化**（Q2）：锥形以 FY05 为圆心**分解成 3 组同心圆**（半径 50/50√5/100 m），**整体复用 Q1(3) 圆形方案**，仅特殊点(共线 FY11/FY15)单独处理；
  5. **迭代逼近**：Δθ 反复迭代至 <1e-16 收敛。
- **降维/简化巧思**：对称性归并、题目转化(判编号)、归化(锥形→圆)——都是"巧劲"。
- **反查**：我采用"统一方向角最小二乘 + 离散假设检验唯一性 + 迭代定点 + 锚点自举 + CRLB/D-最优"。优文**分类讨论更工程彻底、归化更有巧思**；我**理论更系统**（唯一性用离散假设逐槽位穷举、CRLB、三板斧+独立验算）。**本题目"几何分类+对称归并+队形归化"是我最该补的**。

## 维度 2 · 假设的合理性思维

- **数量**：仅 **3 条**（信号稳定 / 忽略处理时间 / **无人机知道自身编号及相对位置关系**）；官方口径 4-6 条，**偏少**。
- **三件套**：①②有依据但**未写"对模型的影响"**；③"知道相对位置"是**强假设**（Q1(2)=1 架答案的前提），但**未显式说明该假设的风险/失效场景**，且后续未做"假设失效"的稳健性检验 → **假设与检验脱节**。
- **反查**：我 6 条、每条含依据+影响、**显式把"偏差小"先验作为消除镜像的关键假设**并指出作用 → 我优；但仍需"**每条假设与后续检验挂钩**"（三件套+可检验+风险显式化）。

## 维度 3 · 我的不足与欠缺（具体定位）

1. **没想到"几何分类讨论 + 对称归并"**：我第一反应是"统一最小二乘"（一个模型通吃）；优文分 3 类×9 形态归并成 6 个解析模型 → **建模思路差距**（先分类再归并，自然产生多图、体现严谨）。
2. **没想到"定位→先判编号"的转化**：优文用"间隔数 n 反推编号+镜像消除"，可手算；我用"离散槽位假设+全角度一致性校验"（通用但抽象）→ **工程性转化差距**。
3. **没想到"新队形→归化已解问题"**：Q2 我独立建锥形模型；优文分解同心圆复用 Q1(3) → **模块复用/归化差距**。
4. **"每问建模前先画坐标/几何示意图"习惯弱**：优文 Q1(1) 分 3 类各配几何示意图；我只有数据/结果图 → **与 2022A 教训一致，最该补**。
