# 老哥·问题分析写作（p51 视频学习笔记）

> 来源：老哥 p51「问题分析写作」。

## 问题分析的定义

把具体问题**抽象为数学模型的桥梁**——反映对问题的认识、给出建模思路，起承上启下作用，体现综合水平。

## 问题分析与摘要的不同（4 条）

1. 问题分析描述过程比摘要**简单**（不用像摘要那么浓缩）；
2. 问题分析**不含结论/求解结果**（只说思路，不说答案）；
3. 可结合**已知条件/背景知识**展开；
4. 可用**流程图/思维导图**辅助（呼应获奖技巧 4：问题分析配流程图）。

## 写法示范（防护服传热题）

"原问题"：给厚度/环境温度/实测皮肤温度 → 求温度分布。
"问题分析"写法：要求温度分布 → 需结合传热方式与边界条件**建立各层传热模型** → 未知参数通过"传热模型 + 实测温度"建立数值关系求解 → 用最优参数算分布。
（比摘要展开：摘要只说"建 PDE + 最小二乘 + 有限差分 → 得参数 113 和 0.344"；分析部分讲清"为什么这么建模"。）

## 验收题（学习闭环）

> 写"烟幕遮蔽"题的问题分析：① 说清"要求遮蔽时长 → 需建什么判定 → 哪些参数待求"三步思路；② 注意不能含什么（呼应与摘要的 4 区别）。
