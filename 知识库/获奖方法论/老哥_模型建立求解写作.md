# 老哥·模型建立与求解写作（视频学习笔记）

> 来源：老哥课程 p54「模型建立与求解写作」（56 分钟，画面逐帧学习）。

## 铁律：数学模型是最重要的

- 建模比赛，**无数学模型 = 大大影响评价**。
- 模型三要求：① 基本正确、简明、便于求解；② 有根据、能详述建模逻辑；③ 实用有效，以解决问题为原则。
- 正文写作流程：问题重述 → 问题分析 → 模型假设 → 符号说明 → **模型建立与求解** → 模型检验。

## 按题型分类的建模写法（最常用套路）

### ① 统计分析类（第一问常见，难度小）
- 无需复杂数学模型，以数据统计分析为主。
- **想出彩必须做足数据检查处理**：异常值检测、数据插值拟合等（这是拉开差距处）。

### ② 评价类建模三步
1. **建立指标体系**：代表性、确定性、独立性、区别能力
2. **规范化处理**：指标一致化处理（正负向）、无量纲化处理
3. **确定权重**：主观赋权法（AHP）或客观赋权法（熵权）

### ③ 优化类建模
- 转化为：**决策变量 + 目标函数 + 约束（不等式组）**
- 常见目标："时间最短""成本最小""收益最高"

### ④ 结合已有模型求解（最常用）
- 按适用条件分评价/预测/优化类，同类题目模型也不尽相同——**先定题型再选模型**。
