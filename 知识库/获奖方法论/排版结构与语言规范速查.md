# 排版结构与语言规范速查（对齐国奖论文的"第一印象分"）

> 来源：2018A 高温作业服"我们 vs 国奖优秀论文"对比分析发现的最实差距。
> 定位：`国赛论文写作总纲.md`（章节骨架）之上的**排版/语言细节规范**——国奖评委给"第一印象分"就看这些。与 `示意图绘制规范.md`、`降AI写法.md` 互补。
> 用法：Phase 3 写论文时先过一遍本节，重点补"模型准备背景知识章 + 朴素标题 + 书面语"。

---

## 一、章节结构：一定要有"模型准备/背景知识"章（✅ 国奖标配，我们最容易漏）

国奖优秀论文（如 2018A）的标准骨架，**在第5章专门安排"模型准备"**，先系统铺垫物理/数学原理，再进具体建模。这是"让评委先懂原理、再看建模"的高级感来源。

```
题目 → 摘要(关键词)
→ 1 问题重述(1.1背景 1.2求解问题)
→ 2 问题分析(每问一小节,写清"这问本质是什么、打算怎么打")
→ 3 模型假设   → 4 符号说明(表:变量/说明/量纲)
→ 5 模型准备(★关键,专门铺垫原理,见下)
→ 6/7/8 各问: 问题分析→模型建立→模型求解→结果展示检验(→模型扩展)
→ 9 模型推广与分析 → 参考文献 → 附录(核心程序)
```

### 第5章"模型准备"应包含（按2018A范本）
1. **背景知识**：涉及的物理/数学定律，逐个铺垫——如热传导的"三种传热方式"(传导/对流/辐射)、Fourier定律、牛顿冷却公式、三类边界条件、稳态vs非稳态、斯泰潘-玻尔兹曼辐射定律。
2. **模型维数/坐标建立**：为什么能做简化（如"三维→一维"），给出理由（边界均匀/无其他热源），并画坐标系/示意图。
3. **本问题的特殊简化处理**：如"辐射可忽略，后续验证"。
4. **各组成部分的传热方式**：逐层说明每部分用哪种传热方式、边界条件类型。

> **自检**：写论文前问"我有没有独立一章先铺垫原理？"——缺了这章，评委会觉得"模型是凭空冒出来的"。**国奖高级感的一半在这章。**

### ⚠️ 注意：模型准备是"铺垫原理"，不是"重复题目"。
- 铺垫的是**通用的物理/数学背景**（Fourier定律、三类边界条件介绍），不是复述题目背景。
- 要与"问题重述"区分：问题重述是复述题目，模型准备是讲**你要用的原理**。

## 二、标题命名：朴素、清晰、直白（别炫技）

国奖标题的特点是**"章节+核心对象"直白命名**，一眼看懂：

| ❌ 我们易犯（太"方法论味"） | ✅ 国奖风格（朴素清晰） |
|---|---|
| "约束进建模 + 多策略真优化" | "模型优化" / "优化模型" |
| "基础模型：厚度-约束的黑箱枚举" | "基础模型" |
| "双变量约束优化 + 加权合成多目标" | "多目标优化模型" |
| "逆传热参数反演" | "换热系数参数估计" |
| "物理传热模型" | "传热控制方程" |

### 命名规则
1. **标题只写"这一节讲什么"，不写"用什么高级方法"**。方法细节放正文，标题保持朴素。
2. **层级编号规范**：一级=问题（"6 问题一：非稳态传热模型"），二级=步骤（"6.2 模型建立""6.3 模型求解"），三级=具体对象（"6.2.1 传热控制方程"）。三级递进，不跳。
3. **避免：**"真优化/黑箱/双变量+加权/结构级"这类修饰词塞进标题——它们让标题变长、变高级，但失掉清晰。

## 三、语言表述：学术书面语（教科书式平实）

国奖语言=**正式、客观、连贯、书面**，像学术报告，不像理工日记。

| ❌ 偏口语/技术味 | ✅ 书面学术语 |
|---|---|
| "注意，这里……" | "需要指出的是……"（但少用） |
| "此处 q 为……" | "式中：q 为热流密度，λ 表示传热系数" |
| "这个过程……" | "该过程……"/"上述过程……" |
| 句式偏短、列步骤 | "由于……因而……"/"由能量守恒定律，建立……"因果长句 |

### 书面语要点
1. **因果链清楚**："由于边界条件均匀分布，热传递可看作只在一个方向进行，因而考虑简化为一维传热模型。"——先因后果，通顺连贯。
2. **每段讲一件完整的事**：先陈述原理→再给依据→再下结论。段落可较长，别一段挤两三件事。
3. **减少口语词**：少用"注意/其实/说白了/这里"，多用"式中/该/上述/由…可知"。
4. **公式后必有"式中"解释**：每个公式都要"式中：X 表示…，Y 表示…"，把符号含义和量纲带上（尤其量纲列规范）。
5. **"我们"要克制**：正文用"本文/该模型/由…可得"，尽量客观（可少量"我们"增强人味，见降AI写法）。

## 四、符号说明表（规范三列）
独立成表，**变量/说明/量纲**三列，放模型假设后、模型准备前。示例：
```
表1 符号说明
变量      说明            量纲
λj       第j层导热系数    W/(m·℃)
ρj       第j层材料密度    kg/m³
Cj       第j层比热容      J/(kg·℃)
h1       第Ⅰ层外界对流   W/(m²·℃)
d_j      第j层厚度       mm
```
