## 一、Matlab 绘图体系（老哥框架）

### 1. 基本绘图命令
| 命令 | 用途 | Python 对应 |
|------|------|-----------|
| plot | 二维曲线 | plt.plot |
| fplot | 函数曲线 | np.linspace+plot |
| ezplot | 隐式/符号曲线 | sympy/solve 后 plot |
| subplot | 多子图 | plt.subplots |
| grid on/off/minor | 网格线 | ax.grid |

### 2. 坐标系
| 命令 | 用途 | Python 对应 |
|------|------|-----------|
| polarplot | 极坐标 | plt.subplot(polar=True) |
| semilogx/semilogy | 半对数 | ax.set_xscale/yscale("log") |
| loglog | 双对数 | 两者都设 |
| yyaxis | 双 y 轴 | ax.twinx() |

### 3. 图形窗口/标注
- figure 属性、工具条（数据游标查看数值）
- 标注：legend/label/title/annotation（我在图表库已内置）

### 4. 三维与特殊图（p75/76）
| 图 | Matlab | Python |
|----|--------|--------|
| 三维曲线 | plot3 | ax.plot(3D) |
| 三维曲面 | surf/mesh | ax.plot_surface |
| 三维散点 | scatter3 | ax.scatter(3D) |
| 三维矢量场 | quiver3 + surfnorm | ax.quiver(3D) |
| 场图/流线 | quiver/streamline | ax.quiver/streamplot |
| 等高线+梯度 | contour+quiver(gradient) | ax.contour + 箭头 |
| 罗盘图 | compass | polar + 箭头 |

### 5. 19 款图类型（p76 概览）
二维曲线、条形、场图、三维散点/曲面/矢量场、球面坐标等——**图的类型选择逻辑**：趋势→折线、对比→柱状、分布→直方/箱线、场→quiver、3D 曲面→surf。

## 二、关键绘图技巧（从老哥视频提炼）

1. **meshgrid 先建网格**（三维绘图前提）：[X,Y]=meshgrid(x,y)，X 每行同 x、Y 每列同 y。
2. **hold on** 多图叠加一个窗口（Python 同 ax 上多次 plot）。
3. **等高线 + 梯度箭头** 组合最能展示"二维函数 + 优化路径"。
4. 数据游标可交互查数值（写论文前自查用）。
