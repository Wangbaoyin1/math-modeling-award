# 优秀论文全方位拆解规范（元标准）

> 这是今后**所有优秀论文分析**必须遵循的拆解维度清单。目的：不只"看它用了什么模型"，而是**多维度吃透一篇国奖论文的可迁移价值，并反查自己的不足**。
> **数值核验**：拆解时除学习结构/写作外，必须**反向核验参考论文的数值**（国奖也会错——漏√2、线性化当精确、读错图、单位口径）。详见《获奖方法论/优秀论文数值反向自检法.md》（含六步自检清单 + 比值量交叉验证），并记入《失败模式库.md》#19。
> 建立时间：2026-09（用户明确要求）。适用：国奖论文拆解、真题复盘、插件审稿。

## 六大必拆维度（每篇论文都要覆盖，缺一不可）

### 维度 0：摘要（评委第一眼，先于一切拆解）

> 摘要决定整篇论文起评分，是评委批判性第一眼。拆任何优秀论文，**先拆它的摘要**，再进正文。

- **量化结果**：摘要里每问有没有"方法 + 带单位数值"？（只有"效果显著"= 淘汰）
- **每问对应**：题目几问，摘要是否逐问覆盖？漏一问 = 硬伤；
- **模型名具体度**：说"神经网络"还是"BP 神经网络"？说"优化模型"还是"多目标整数规划"？
- **四段式结构**：前言(背景+思路) / 建模(方法+假设) / 求解(数据+软件+算法) / 结果(数值+检验+结论升华)是否完整？
- **字数与版面**：800-1000 字、单独一页、无图表？
- **AI 味**：有没有"针对XX本文提出XX"的模板化开头、套话堆砌？
- **反查自己**：我的摘要习惯上会漏掉这 6 点里的哪几点？

### 维度 1：建模的创造性思维
- **问题重构**：它如何把赛题重述成一个数学问题？有没有"换个角度定义问题"（而非照抄题面）？
- **核心量定义**：它选了哪 2-3 个核心量贯穿全文？为何选这些（是否比直觉更本质）？
- **创新落点**：创新具体落在哪一问、哪个环节？（是模型、是求解算法、是判据、是降维，还是问题转化？）创新是否"为创新而创新"还是真正解决了本题难点？
- **组合/迁移思维**：它是"经典模型 + 改进"，还是"跨领域迁移"，还是"多模型融合"？迁移得是否自然？
- **降维/简化巧思**：有没有"对称性降维""先证后搜""问题等价转化"之类的巧劲？

### 维度 2：假设的合理性思维
- **每条假设的"三件套"是否齐全**：①假设内容 ②合理性依据（有数据/量级支撑，还是空话）③对模型的影响；
- **假设数量**：是否 4-6 条（官方口径）、有无过度假设/致命假设；
- **有没有"显式说明假设的风险"**：好的论文会指出"假设 X 在 XX 情况下失效，将在灵敏度分析检验"；
- **假设是否可检验**：哪些假设在后续被灵敏度/稳健性覆盖了？
- **反查自己**：如果是我，会不会漏掉某条关键假设？会不会过度简化？

### 维度 3：自己的不足与欠缺
- **我拿到这道题会怎么做**：我的第一反应解法是什么？与它的差距在哪？
- **具体差距定位**：是"没想到这个模型"？还是"想到但不会推导"？还是"会推导但代码/求解做不到"？还是"做得出但写作/检验不到位"？
- **可复用的补短板项**：这条差距对应我知识库/能力树的哪个缺口，记一条具体待补。

### 维度 4：数据图片的质量（客观评图）
- **图是否出版级**：分辨率/配色（是否默认 matplotlib 配色）/字体（中文是否正常）/坐标轴单位/图例完整度；
- **图的信息量**：图注是否 30-50 字且"说出发现了什么"，还是只说"图1 XX对比"？
- **图的类型选择**：该用折线用了折线？该用热力用了热力？有没有更合适的图型？
- **图的数量与分布**：每问是否 ≥1 图？关键结论是否有图支撑？
- **三线表/表格规范**：是否三线表、编号连续、表头单位齐全。

### 维度 5：图片效果的不足（反查改进方向）
- **它的图哪里还不够好**：配色普通？缺误差棒？图注空泛？中文方块？等值线粗糙？
- **如果我来画，能怎么更好**：对照我的 `图表库.py`，写出"可升级点"（如加 Paul Tol 色板、加龙卷风图、加标注）。

### 维度 6：还需要学的地方（学习清单）
- **本文暴露了我的哪些知识盲区**：具体到"XX 方法我还不会/不熟"；
- **下一步学习行动**：对应到知识库补哪条、或工具箱补哪个函数、或评测集跑哪道题。

## 拆解产出格式（统一模板）

每篇论文拆解笔记，除正文外，末尾必须附一张「六维拆解表」：

| 维度 | 本论文的亮点/做法 | 我的差距/不足 | 可迁移点/待补项 |
|------|------------------|--------------|----------------|
| 0 摘要第一眼 | | | |
| 1 创造性思维 | | | |
| 2 假设合理性 | | | |
| 3 我的不足 | | | |
| 4 图片质量 | | | |
| 5 图片不足 | | | |
| 6 待学清单 | | | |

## 执行纪律

1. **不跳过维度**：即使某篇论文某维度"无特别亮点"，也要写"常规，无突出点"而非省略；
2. **差距要具体**：不写"我水平不够"，写"没想到用 PMF 受体模型定量贡献率，对应知识卡 07 已补但还需真跑一次"；
3. **图要真看**：分析图片质量必须实际读图（modlens/read_image），不能凭文件名猜；
4. **每条"待学"要落地**：待学清单必须能对应到知识库/工具箱/评测集的具体位置，不空转。
