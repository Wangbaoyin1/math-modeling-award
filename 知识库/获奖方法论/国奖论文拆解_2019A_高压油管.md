## 维度 1 · 建模的创造性思维

- **问题重构（我学）**：先立**非定常可压缩流体的 1D PDE**（质量/动量/能量守恒，速度/密度/压强三变量），文中再"简化为压强均匀"——**先扬后简**的建模叙事，比我的直给集总 ODE 物理起点高半档。
- **核心量**：`P_{i,j}`/`ρ_{i,j}`（横截面×时间离散），体量大于我的 `P(t)`。
- **积分型质量守恒 + LCM 周期**：`(1-12)` 积分密度模型 + `(1-14) T=T_in·T_out`——比我的"单周期验证"更严谨。✓ 可学。
- **多项式拟合**：`(2-1)` 6 阶多项式拟合凸轮 r(θ)，`(2-9~2-12)` 针阀面积解析式，`(附录)` 针阀有效面积分段多项式——**统一为解析/分段式**，便于求导与建模。✓ 可学（我用 PCHIP+数值差分）。
- **遍历求解（先粗后细）**：Step1-5 步长 0.1→0.01→/10 多轮细化，误差阈值(<0.01mg)停止——**工程化、通用、可复现**；我多用解析+ODE。✓ 可学。
- **方案 1/方案 2 对比决策（我学、我的最弱项）**：减压阀"阈值开(ω,波动0.1036MPa) vs 周期开(ω=48,波动2.678MPa)"，用指标取舍选阈值开。**这是最有价值的创新点**——多方案对比 + 决策链，我 3b 只做了阈值开，缺"周期开"对照。
- **稳定性检验**：6.3 加"进油周期在标准周期 20% 范围内浮动"的扰动，看压力波动——**控制方案抗干扰性**，我 3b 缺。
- **降维巧思**：LCM 周期 + 定积分平衡，把周期稳态数学化。

## 维度 3 · 我的不足与欠缺 + 该文真正的硬伤（逐条对表）

**关键发现——该文有 3 处硬伤，且互相叠加成 P1 的 ~10 倍误差：**

1. **压力-密度关系根本错误（P=kρ 用错比例系数）**：`(1-22) P=117.65ρ`，而 117.65 = P_ref/ρ_ref = 100/0.85（**只取参考点比值，忽略了斜率！**）。注1 正确应为 `dP/dρ = E/ρ ≈ 2171/0.85 ≈ 2554`。**117.65 vs 2554，差了 ~22 倍**——使该文对"密度随压变化"高估 22 倍，这是 d100=0.29ms 错误的**主根因**。
2. **漏 √2**：`(1-4) Q_in=C·S_d·√(ΔP/ρ₁)`、`(1-5)`、`(2-13)` 均漏了注2 的 `√(2ΔP/ρ)` 里的 **√2**；但 `(2-27) 减压阀` 又用 `√(2(P₁-P₂)/ρ₁)` **含 √2**——**前后矛盾，是复制笔误**。
3. **喷油峰误读**：d100=0.29ms ⇒ 注入仅 ≈4.4mm³（喷油峰被当成 2），而图2 峰应为 **20**（注入 44mm³）；与其图5 的**进出质量不守恒**（进≈3.8mg vs 出≈40mg/周期）矛盾。

**正反验证（该文虽 P1 错，但比值量与我高度吻合，反证我的正确性）：**

| 量 | 该文 | 我 | 吻合度 |
|---|---|---|---|
| P2 凸轮角速度 ω | 27.199 rad/s | 27.3（平均平衡）/26.6（ODE） | 差 0.4% ✓ |
| P3 双喷 ω | 48.33 rad/s（摘要 483.33 是 ×10 笔误） | 54.6 | 差 12% ✓ |
| d150/d100 比值 | 0.72/0.29 = 2.48 | 6.99/2.80 = 2.50 | 差 0.8% ✓ |
| 针阀有效面积 | min(环隙,喷孔1.5394) | min(环隙,喷孔1.5394) | 一致 ✓ |
| 管容积 V_t | π·5²·500=39270 | 39270 | 一致 ✓ |
| 减压阀 | 阈值开(0.1036)优于周期开(2.678) | 阈值开稳压 | 结论一致 ✓ |
| 喷油背压 P₀ | 0.1 MPa | 0.5 MPa（稳健性显示影响<0.3%） | 轻微差异 |

> **结论**：该文**绝对量（d100）错**（k 误差+漏√2+峰值误读），但**比值量（ω、d150/d100）对**且与我吻合。说明：**我的 d100=2.8ms（含√2、精确积分 ρ(P)）才是物理正确**；它的错误源于数值口径，**不可作为数值参考，可作为结构/写作参考**。

## 沉淀教训（写入《失败模式库》认知）

**国奖论文示例也最易犯的"数值口径"三错**：①把 `E/ρ`(≈2554) 当作 `P/ρ`(117.65)，差 22×；②注2 的 `√(2ΔP/ρ)` 漏 √2（还与自身某处含 √2 矛盾，属复制笔误）；③把图上喷油峰 `20` 误读为 `2`。三者叠加 → P1 绝对量错 ~10 倍，但**比值量仍对**。

> **铁律**：①**比值型结果（ω、比率、无量纲）比绝对量稳健**，可用于交叉验证；②**参考国奖的"结构与写作"，不盲信其"数值"**——数值必须用独立守恒（质量守恒）+ 比值量自检；③**数值要能自洽**（进出质量守恒），不能互相抄。这条已由"√1000 口径疑点 + 本次 k=117.65 揪错"双重印证。
