# 老哥·突破解题障碍（p110 赛题解析二）

> 来源：老哥 p110「突破解题障碍」，讲"遇到难题怎么破"。

## 一、文献查找技巧（信息不够时）

| 模式 | 组成 | 适用 |
|------|------|------|
| A | 知网 | 入门 |
| B | 中外文献数据库 | 进阶 |
| C | 数据库 + 学术论文 | 常规 |
| **D** | **数据库 + 学术论文 + 搜索引擎** | **国赛推荐** |

- 附加两招：**看文献的参考文献**（顺藤摸瓜）+ **找综述文章**（快速入门一个领域）。

## 二、创新切入点清单（最关键，找到"从哪下手创新"）

| 切入点 | 具体做法 |
|--------|---------|
| **数据处理** | 异常值、残缺值、服从某种分布——从数据本身找创新 |
| **优化模型** | 目标函数、决策变量的**巧妙切入**（换个角度定义变量/目标） |
| **分级评价·多级指标** | 区分"实际存在的量"vs"抽象量"，多级指标分层 |
| **加权评判函数** | 不同变量赋不同权重（而非等权） |
| **阈值·特殊情况** | 阈值设多少、特殊情况特殊分析（靠自己推） |

## 三、与我风格库的呼应

这些切入点 = 国奖风格库"创新模板"的具体化：
- "权衡成本化" ← 优化模型巧妙切入（目标函数双成本）
- "个体化分组" ← 阈值/分级
- "分解建模" ← 分级评价·多级指标

> 通用心法：**卡住时，从"数据、目标函数、指标、权重、阈值"五个角度找创新切入**，几乎总有一个能打开局面。

## 验收题（学习闭环）

>
