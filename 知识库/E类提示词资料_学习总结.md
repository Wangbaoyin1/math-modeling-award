## 二、关键统计结论（影响选题与备考方向）

**近五年 15 道本科组题：优化类 11 道、机理类 8 道 = 绝对主流；评价类 2 道、预测类 4 道。**
- A 题几乎全是"机理 + 优化"（定日镜/波浪能/FAST/乙醇/板凳龙/烟幕/碳化硅）；
- B 题是"优化 + 机理"（无人机定位/多波束/生产决策）；
- C 题是"数据 + 评价/预测"（玻璃成分/蔬菜定价/农作物/NIPT）。
- **结论**：备考重心 = 优化 + 机理（A/B 题）；C 题数据会即可不必深。（已记入 README 待办）

## 三、从提示词提炼的「角色设定精华」（已注入 persona）

这些是提示词资料里反复强调、值得吸收进 persona 的角色设定：

### 设定 1：题目结构化拆解（Phase 0 增强）
- **逐句解析**，表格区分「背景信息/核心问题/已知条件/约束规则/行业物理限定」；
- **每问写"直接目标 + 隐含目标"**（表面求方案、实际要验证可行性）；
- 题型归类附判定依据（不只是归类，要说为什么）。
> 状态：已注入 persona Phase 0（框架设计从"四项"变"五项"）。

### 设定 2：每问"2 方案"结构（Phase 1 增强）
- **方案1 基础适配**（经典模型 + 改进点）+ **方案2 创新融合**（跨领域组合）；
- 各写 5 项：核心原理(通俗)/场景适配性/真实创新点/局限+规避/建模过程；
- 选定主方案 + 写"为何不选另一方案"；创新仅限三类（算法改进/跨领域迁移/多模型融合）。
> 状态：已注入 persona Phase 1。

### 设定 3：每问固定四模块 + 变量五类（Phase 2 增强）
- 四模块：模型建立 / 求解 / 检验 / 结果分析（缺一不可）；
- 变量三线表分**决策/中间/目标/已知参数/待校准**五类；
- 假设 3-5 条，每条含"内容+依据+影响"；公式≥10 个并规范编号。
> 状态：已注入 persona Phase 2。

### 设定 4：摘要结构规范（Phase 3 已有，此处校准）
- 摘要"背景→问题→方法→结果→结论"，800-1000 字、≤1 页、无图；
- 每段"针对问题X"开头（注意与降AI"避免模板化"的张力——用"针对问题X"时后面必须紧跟具体内容，不要空泛）。
> 状态：persona 已有摘要四段式，此处补充字数硬规范（已在 2026 合规文档落地）。
