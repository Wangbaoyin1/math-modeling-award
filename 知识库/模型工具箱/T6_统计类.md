# T6 · 统计分析类（工具箱）

> 用途：从数据找关系、差异、结构。数据题必备。
> 方法论对齐 UltraMath《统计分析类》《聚类分析类》，本篇补**可运行代码模板**。

## 一句话核心

统计题 = "从数据里找关系/差异/结构"。关键第一步是**明确统计目标**（检验差异？找相关？降维？聚类？判别？），目标不同方法完全不同。

## 目标 → 方法对照

| 统计目标 | 方法 | 一句话 |
|---------|------|--------|
| 检验差异 | t 检验 / 卡方 / 方差分析 | A、B 两组有显著差别吗 |
| 找相关 | Pearson/Spearman 相关、回归 | x 和 y 有关系吗 |
| 降维 | 主成分 PCA、因子分析 | 用少数变量概括多数 |
| 聚类 | K-means、层次聚类 | 把对象自然分组 |
| 判别 | 判别分析、SVM | 新样本属于哪类 |

## 代码模板（⚠️ 赛前需在真实环境验证）

### 1. 假设检验（scipy.stats）
```python
from scipy import stats
t, p = stats.ttest_ind(a, b)     # 两独立样本 t 检验
print("p =", p)                  # p < 0.05 → 有显著差异
r, pr = stats.pearsonr(x, y)     # Pearson 相关系数
print("r =", r, "p =", pr)
```

### 2. 主成分分析 PCA
```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
X_std = StandardScaler().fit_transform(X)     # PCA 前必须标准化
pca = PCA(n_components=2).fit(X_std)
X_pca = pca.transform(X_std)
print("方差贡献率 =", pca.explained_variance_ratio_)
```

### 3. K-means 聚类
```python
from sklearn.cluster import KMeans
km = KMeans(n_clusters=3, random_state=42, n_init=10).fit(X_std)
labels = km.labels_
print("簇中心 =", km.cluster_centers_)
```

## 关键点与坑（失败模式）

- [ ] 检验前看**前提**：t 检验要近似正态、方差齐；不满足换非参数（Mann-Whitney）
- [ ] `p < 0.05` 只说明"**显著**"，不说明"差异有多大"——要同时报效应量
- [ ] **PCA/聚类前必须标准化**（量纲不同会主导结果）
- [ ] K-means 的 k 要用**肘部法/轮廓系数**定，别拍脑袋
- [ ] 相关 ≠ 因果（"相关系数高"不代表"A 导致 B"）
