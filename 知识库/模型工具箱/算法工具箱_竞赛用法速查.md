## 二、组合套路（国赛论文加分写法）

1. **评价题万能链**：熵权/AHP 定权 → TOPSIS 排序 → 灵敏度/稳健性（换 PCA 权或换权法对照）。
2. **预测题对比链**：GM(1,1)（趋势）+ 回归/BP（残差修正或对照），三模型结果表 + 误差指标对比 → 证明选型合理。
3. **优化题递进链**：LP 建模（严谨）→ 解不动就 MILP/非线性 → 仍不行上智能算法给"增强解" → 多初值/多算法互证 + 灵敏度龙卷风图。
4. **影响因素题**：先相关性/灰色关联筛主因 → 对主因回归定量 → 再做残差检验。
5. **双目标题**：加权 + 扫偏好系数画 Pareto 曲线（比直接丢 NSGA-II 更容易被看懂）。
6. **污染溯源题链**：富集系数标准化 → IDW/克里金建场 → 梯度场+峰值聚类粗定位源区 → 功能区交叉佐证 →（有气象/源谱再升级高斯烟羽/CMB/PMF 定量贡献）→ 合成场残差图验证。**有几斤数据做几斤结论**：无气象数据就老实报"描述性定位 + σ 量级估计"，别硬报 R²≈0 的反演。

## 三、通用建模纪律（视频反复强调 + 实战教训）
- 每个模型：**变量 → 目标 → 约束 → 一句业务解释**；约束残缺是最大死因（失败模式 #5）。
- 智能算法前先写清 `min f(X) s.t. 边界/不等式/等式`；初值/种群/降温参数要试，别只跑一次（#6 局部最优）。
- 结果必配**检验**：误差分析 + 灵敏度分析 + 稳健性分析**三板斧**（详见 `底层逻辑/05` v2）；回归 F/R²、AHP CR、GM C/p、神经网络测试集误差。
- 图比表好，表比文字好；全部图走 `图表库.py`（SimHei 已修）。
- 数据先看（散点/直方），模型先简后繁，敏感度小扰动 ±5%（#9 教训）。

## 三·五、四大题型识别 + 选型口诀（老哥题型汇总）

**四大题型区分（看问句关键词）**：
| 题型 | 关键词 | 特征 |
|------|--------|------|
| 优化 | 最优/最大/最小/如何安排 | 必有决策变量 |
| 评价 | 评估/比较/排序/优劣/综合水平 | 研究对象 ≥2 个方案 |
| 预测 | 预估/预测/未来走势 | 历史数据→未来数值 |
| 机理 | 机理/规律/演化过程 | 需物理/工程原理建方程，数据反演参数 |

**优化选型口诀**：能小数式子直→LP；必须整数不能碎→IP；选或不选二选一→0-1；平方乘积曲线变→NLP；又要赚钱又省钱→多目标；排列组合找最优→组合优化(智能算法)。

**评价选型口诀**：无数据靠经验→AHP；有数据要公正→熵权；比优劣排顺序→TOPSIS；评等级很模糊→模糊综合；数据大求精准→机器学习。高分组合：AHP+TOPSIS（少数据）/ 熵权+TOPSIS（多数据）/ AHP熵权+模糊（定性）/ ML+传统对比（创新）。

**机理选型口诀**：找原因析影响→因果归因（偏相关/灰色关联/SHAP/回归系数）；物理变高精度→微分方程；拆系统理框架→结构机理；看反馈长期演化→系统动力学。
