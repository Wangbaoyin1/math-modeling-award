# T4 · 图论类模型（工具箱）

> 用途：网络、路径、连通、覆盖类问题。
> 方法论对齐 UltraMath《图论类》，本篇补**可运行代码模板**。

## 一句话核心

图论题 = "节点 + 边 + 权重"的结构问题。关键第一步是**识别这是哪类图问题**（最短路 / 最小生成树 / 网络流 / 匹配 / 巡回），再选算法——识别错了，后面全错。

## 常用问题与算法

| 问题 | 算法 | 典型场景 |
|------|------|---------|
| 单源最短路 | Dijkstra（非负权） | 路径规划、导航 |
| 全源最短路 | Floyd / Johnson | 任意两点距离 |
| 负权最短路 | Bellman-Ford / SPFA | 有负权边 |
| 最小生成树 | Prim / Kruskal | 布线、网络铺设 |
| 最大流 | Dinic / Ford-Fulkerson | 运输、分配上限 |
| 最小费用最大流 | 增广路 + 最短路 | 运输 + 成本 |
| 二分图匹配 | 匈牙利算法 | 任务分配 |
| 旅行商 TSP | 动态规划 / 启发式 | 巡回路径 |

### 1. 最短路（networkx，最省事）
```python
import networkx as nx
G = nx.Graph()
G.add_weighted_edges_from([(1, 2, 5), (2, 3, 3), (1, 3, 10)])
path = nx.shortest_path(G, source=1, target=3, weight="weight")
length = nx.shortest_path_length(G, source=1, target=3, weight="weight")
print(path, length)
```

### 2. Dijkstra（手写，无第三方依赖）
```python
import heapq
def dijkstra(graph, start):
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:            # graph[u] = [(邻点, 权重), ...]
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

### 3. Floyd（全源最短路，n 较小时）
```python
def floyd(n, edges):
    INF = float("inf")
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = w
    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    return dist
```


## 关键点与坑（失败模式）

- [ ] Dijkstra **不能有负权边**（负权用 Bellman-Ford/SPFA）
- [ ] 有向图 / 无向图搞混（边是单向还是双向）
- [ ] 网络流要先**建模**：设源点、汇点、边容量，别直接套模板
- [ ] TSP 是 NP 难，n 大时用**启发式**而非精确枚举
- [ ] 多重边、自环要预处理干净
