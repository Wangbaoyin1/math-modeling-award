# T10 · 物理光学与干涉机理类（工具箱）

> 定位：2025B（红外干涉测厚，国一）暴露的知识盲区补充——**物理光学类 A/B 题的建模骨架**。
> 触发特征：题目含"反射光谱/干涉条纹/薄膜厚度/折射率/波长"等词 → 光学干涉机理题。

## 一句话核心

光学干涉测厚 = **两层模型链**：①**干涉模型**（光程差 → 相位差 → 反射率）把厚度 d 映射到光谱 R(σ)；②**色散模型**（折射率随波长变化 n(σ)）决定干涉条纹形态。然后**逆问题反演**：调参数让理论光谱拟合实测光谱。

## 核心知识链（按建模顺序）

### 1. 双光束干涉（基础）
光在"空气-膜-衬底"三层：光束1 空气/膜界面直接反射，光束2 穿膜→衬底反射→穿出，二者干涉。
- **光程差**：$\Delta L = 2n_1 d \cos\theta_2$（由几何 + 斯涅尔推出，见 2025B 推导链）
- **相位差**：$\delta = \frac{4\pi n_1 d \cos\theta_2}{\lambda_0} + \Phi_{sub} - \Phi_{air}$（含界面反射相位突变）
- **反射率**（非偏振光 = s/p 非相干叠加）：$R = (I_s + I_p)/I_0$

### 2. 菲涅尔方程（算各光束振幅）
从介质 i 到 j，s/p 偏振振幅反射系数：
$$r_s = \frac{n_i\cos\theta_i - n_j\cos\theta_j}{n_i\cos\theta_i + n_j\cos\theta_j}, \quad r_p = \frac{n_j\cos\theta_i - n_i\cos\theta_j}{n_j\cos\theta_i + n_i\cos\theta_j}$$
（透射系数 t 类似，互易关系 $tt' - rr' = 1$ 常用）
光束2 振幅 = t(0→1)·r(1→2)·t(1→0)·A₀（多次透射+一次反射的乘积）。

### 3. 色散模型（材料定制，关键创新点）
| 材料/情形 | 模型 | 说明 |
|-----------|------|------|
| 有晶格振动+自由载流子（SiC 等半导体） | **洛伦兹-德鲁德 Lorentz-Drude** | 复介电函数 ε(ω)=ε∞·(ωL²−ω²−iγLω)/(ωT²−ω²−iγTω) − ωp²/(ω²+iγω)，第一项声子、第二项载流子 |
| 红外透明晶体（Si 等） | **三项塞尔迈耶 Sellmeier** | n²(λ)=1+Σ Bjλ²/(λ²−Cj)，纯色散无吸收 |
| 载流子浓度与 ωp/γ 关系 | ωp²=Nq²/(ε₀m*)，γ=q/(m*μ) | 把光学参数连到电学性质 |
- 复折射率 ñ=√ε，实部=折射率 n，虚部=消光系数 k；折射率是复数时菲涅尔在复数域算（自动含吸收与相位突变）。

### 4. 多光束干涉（膜够亮/界面高反时）
Fabry-Pérot 腔：各级反射光复振幅 Ũ_k 等比求和 → 
$$U_R = \frac{r_1 + r_2 e^{-i\delta}}{1 + r_1 r_2 e^{-i\delta}} A_0$$
**发生多光束干涉的三个必要条件**：① 相干长度 Lc≫2nd·cosθ；② 相邻反射光振幅比 |r₁′r₂e^{−iδ}| 不可太小（量级 ~0.1-1 要考虑，≪1 可忽略）；③ 界面平行光滑、膜厚均匀。
**判据**：光谱精细度 F = FSR/FWHM；双光束 F≈2，多光束 F>2（2025B 算得 Si 的 F≈2.7>2 → 判定存在多光束）。对比度 V=(I_max−I_min)/(I_max+I_min)。

## 逆问题反演（把厚度"解"出来）

1. **建模**：固定参数 → 理论光谱 R_theory(σ)；目标：min Σ MSE（多角度同步拟合更好）；
2. **全局-局部混合优化**：差分进化（种群40、迭代1000、固定seed42）全局粗搜 → L-BFGS-B（容差1e-12）局部精修，避免局部最优；
3. **极值点解析法**（材料透明时）：波峰波谷处相位差=2π·k（k 整数/半整数）→ d=k/(2n(σ_k)cosθ·σ_k)；遍历搜索定干涉级数 m₀（使厚度序列标准差最小者正确）；
4. **色散校正 FFT（旗舰方法）**：直接对 R(σ) FFT 会因相位 δ(σ)=4πd·σ·√(n_f²−sin²θ) 非线性 → 峰宽化偏移。**坐标变换 x(σ)=2σ√(n_f²−sin²θ) 使 δ(x)=2πd·x 线性化** → 重采样到均匀 x 网格 → 汉宁窗 + 去直流 → FFT → 峰位=厚度 d。抛物线拟合峰顶获亚像素精度。

## 检验（物理题三板斧）

- **拟合优度**：R²、残差分布（注意低波数区系统性偏差可能是物理现象 LOPC 而非模型缺陷）；
- **灵敏度**：入射角 ±2%、色散系数 ±1% 扰动看厚度波动；
- **稳定性**：叠加 0.5% 高斯噪声重复 100-200 次蒙特卡洛，看厚度均值是否稳定。

## 关键坑

- [ ] 折射率是**复数**：菲涅尔要算复数域（别用实折射率近似）
- [ ] 量纲：光谱横轴常是**波数 σ=1/λ**（cm⁻¹）不是波长——混了就全错
- [ ] 剔除非物理数据点（如反射率 R=0 首点）
- [ ] 参数固定值**必须来自文献**（4H-SiC 的 ε∞=6.56 等），别编
- [ ] 多角度同步拟合降低解不唯一（单角度 7 参数逆问题常不唯一）
