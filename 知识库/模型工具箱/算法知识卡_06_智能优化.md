# 算法知识卡 06：智能优化类（p89 GA / p92 PSO / p94 多目标 / p96 退火 / p97 差分进化）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角
> 一句话定位：**传统规划解不动（非线性、离散、高维、不可导）时上智能算法找"近似最优"**；国赛用它们是"优化深度加分项"，配合灵敏度分析。

## 0 何时需要智能算法（先判断）
- 目标/约束**非线性、非凸、不连续**，传统求解器（linprog/fmincon）难收敛或总到局部最优；
- **组合爆炸**（排班、路径、选址、0-1 大整数）；
- 要展示"全局搜索能力"或做**多目标 Pareto**。
- 反面：能转线性/整数规划的标准问题别硬上智能算法（评委更认严谨的数学规划解）。
- 所有智能算法**都要求会写目标函数 f(X) 与可行域边界 a≤xᵢ≤b、g(X)≤c、h(X)=d**（视频反复强调"什么是优化"）。

## 1 遗传算法 GA（p89）
**本质**：模拟**自然选择+遗传**的种群搜索（Holland 1975）。与经典优化四点不同：① 对**编码**操作而非参数本身；② **种群**多点搜索非单点；③ 只用目标函数值，**不需要导数**；④ **概率性**规则。
**流程**：编码（二进制/实数）→ 初始化种群 → 适应度评估 → **选择**（轮盘赌/锦标赛）→ **交叉** → **变异** → 下一代 → 收敛输出。
**实数交叉公式**（视频）：
akj' = akj(1−b)+alj·b；alj' = alj(1−b)+akj·b，b∈[0,1] 随机。
**坑**：交叉率/变异率/种群规模调参；约束用**罚函数**处理（把不可行解惩罚进适应度）。

## 2 粒子群 PSO（p92）
**本质**：模拟鸟群觅食：每粒子记住**自身最优 pBest** 与**全局最优 gBest**，向两者飞。
**位置/速度更新（必背公式）**：
- Xiᵗ⁺¹ = Xiᵗ + Viᵗ⁺¹
- Viᵗ⁺¹ = **ω**·Viᵗ + **c₁r₁**(pBest−Xiᵗ) + **c₂r₂**(gBest−Xiᵗ)
  ω 惯性权重（大→全局探索，小→局部精搜，可线性递减）；c₁ 个体学习因子、c₂ 社会学习因子；r₁r₂∈[0,1] 随机。
**优点**：实现简单、收敛快、参数少；**坑**：易早熟（都挤到局部极值）→ 加变异/扰动、惯性权重递减、多峰时配模拟退火跳出。

## 3 模拟退火 SA（p96）
**本质**：模拟金属退火：随机找新解，**以概率接受更差的解**（Metropolis 准则）从而跳出局部最优，温度逐步降。
**流程（视频流程图）**：随机初始解 x₀ → 邻域扰动得 x′，算 Δ=f(x′)−f(x₀) → **Δ<0 接受**；Δ≥0 按 Metropolis 概率 e^(−Δ/T) 接受 → 达迭代次数 → **按退火策略降温** → 满足结束条件输出最优。
**坑**：初温、降温速率（0.9~0.99）、每温迭代次数决定全局性；**解编码与邻域扰动方式**（怎么生成新解）决定效率。
**视频实战**：MCM2020B 沙堡/水下滑翔机类问题——目标函数 f(X) 含几何关系，决策变量 [edgeSize, height, scale, ratio]，带边界约束 → SA 扫参求最大 f。启发：**复杂几何公式题 + 智能算法扫参**是通用套路。

## 4 差分进化 DE（p97）
**本质**：GA 变体，专为**实数连续优化**：用种群中随机个体的**差分向量做变异扰动**，再交叉、贪心选择。
**流程**：初始化 → 变异（V=Xᵣ₁+F(Xᵣ₂−Xᵣ₃)，F 缩放因子）→ 交叉（按 CR 概率混入目标个体）→ 选择（好则留，**贪心**）→ 收敛。
**优点**：结构简单、鲁棒、全局性好，连续优化常优于 GA/PSO；**坑**：F、CR、NP 调参，高维需加大种群。

## 5 多目标优化（p94）
**本质**：同时优化多个冲突目标（收益 vs 风险、成本 vs 质量）。
**核心概念**：
- **Pareto 支配**：解 A 支配 B = A 所有目标不劣且至少一个更优；
- **Pareto 前沿（front）**：所有非支配解构成的目标空间曲线/面——图上红点连成前沿、黑方块是被支配解。
**算法**：NSGA-II（非支配排序+拥挤距离）、MOPSO（外部档案 REP + 自适应网格保持多样性，视频代码 MOPSO.m 的 updateGrid）。
**竞赛简化写法（再次推荐）**：多数题不必真跑 NSGA-II——**加权合成单目标 + 扫偏好系数 s 描 Pareto 前沿**（见知识卡 01 模型三）；真要展示深度才上 NSGA-II/MOPSO 出前沿图。
