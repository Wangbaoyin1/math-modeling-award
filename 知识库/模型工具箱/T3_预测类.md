## 一句话核心

预测题 = "用历史推未来"。关键两件事：**选对模型**（看数据量、趋势、周期性）+ **验证精度**（训练/测试切分 + 误差指标）。只预测不验证 = 评委不信。

## 常用方法对照

| 方法 | 适用 | 特点 |
|------|------|------|
| 线性回归 | 有相关自变量 | 可解释、简单 |
| ARIMA | 单变量时间序列，有趋势/周期 | 经典、可解释 |
| 灰色预测 GM(1,1) | 少数据（≥4 个点）、指数增长 | 小样本利器 |
| 神经网络 | 非线性、大数据 | 黑箱、易过拟合 |
| 马尔可夫链 | 状态转移（离散状态） | 状态预测 |

### 2. 灰色预测 GM(1,1)（少数据）
```python
import numpy as np
def gm11(x0, steps=5):
    x0 = np.asarray(x0, dtype=float)          # 非负原始序列
    x1 = x0.cumsum()                           # 一次累加 AGO
    z1 = 0.5 * (x1[1:] + x1[:-1])              # 紧邻均值
    B = np.column_stack([-z1, np.ones(len(z1))])
    Y = x0[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]   # 灰参数 a(发展), b(灰作用量)
    preds = [x0[0]]
    for k in range(1, len(x0) + steps):
        preds.append((x0[0] - b/a) * (1 - np.exp(a)) * np.exp(-a * k))
    return preds   # 前 len(x0) 是拟合，后 steps 是预测
```

## 关键点与坑（失败模式）

- [ ] **不验证精度**——必须训练/测试切分，报 MAPE/RMSE，否则评委不信
- [ ] 灰色预测只适合**少数据 + 指数趋势**；大数据、强周期用 ARIMA
- [ ] 神经网络在**小数据**上过拟合严重，别硬上
- [ ] 预测只给点值不给**置信区间**（专业度打折）
- [ ] 拿"用全量数据拟合的误差"当预测精度（那是自欺，要用**测试集**误差）
