# T2 · 评价类模型（工具箱）

> 用途：给一堆对象打分排序、选出最优。常见于综合评价题。
> 方法论对齐 UltraMath《评价类》，本篇补**可运行代码模板**。

## 一句话核心

评价题 = "确定评价指标体系 + 确定权重 + 选评价方法"。**最关键的坑是指标"正向化"**——有的指标越大越好（收益）、有的越小越好（成本、价格），混用会得出反的结论。

## 常用方法对照

| 方法 | 权重来源 | 适用场景 |
|------|---------|---------|
| AHP 层次分析 | 主观（专家打分） | 定性指标多、无数据 |
| 熵权法 | 客观（数据离散度） | 有数据，权重由数据定 |
| TOPSIS | 客观（距理想解远近） | 多指标排序，有数据 |
| 模糊综合评价 | 主观 + 隶属度 | 指标模糊、语言评价 |
| 灰色关联 | 客观 | 少数据、贫信息 |

> 最常用组合：**熵权法（定权重）+ TOPSIS（排序）**，既客观又直观。

## 代码模板（⚠️ 赛前需在真实环境验证）

### 熵权法 + TOPSIS（n 个对象 × m 个指标）
```python
import numpy as np

def entropy_topsis(X):
    """X: n×m 矩阵，已正向化(全部指标越大越好)。返回 (得分, 权重)。"""
    X = np.asarray(X, dtype=float)
    n, m = X.shape
    # 1. 熵权法定权重
    Xn = X / X.sum(axis=0)                       # 按列归一化
    k = 1.0 / np.log(n)
    e = -k * (Xn * np.log(Xn + 1e-12)).sum(axis=0)  # 信息熵
    w = (1 - e) / (1 - e).sum()                  # 熵权，和为 1
    # 2. TOPSIS 排序
    Z = X / np.sqrt((X ** 2).sum(axis=0))        # 向量归一化
    Z = Z * w                                     # 加权
    best = Z.max(axis=0); worst = Z.min(axis=0)
    d_best = np.sqrt(((Z - best) ** 2).sum(axis=1))
    d_worst = np.sqrt(((Z - worst) ** 2).sum(axis=1))
    score = d_worst / (d_best + d_worst)          # 贴近度，越大越优
    return score, w
```

### 指标正向化（先做！）
```python
def positive(X, cols_negative):
    """把'越小越好'的列取倒数，转成'越大越好'。cols_negative 是负向指标列索引。"""
    X = X.astype(float).copy()
    for j in cols_negative:
        X[:, j] = 1.0 / (X[:, j] + 1e-12)         # 成本/价格类取倒数
    return X
```

## 关键点与坑（失败模式）

- [ ] **负向指标没正向化**（价格、成本、耗时越小越好，直接混用会排反）
- [ ] 熵权法要求数据**非负**，有负数先平移或换方法
- [ ] 指标量纲不统一（收益是万级、比例是小数）→ 必须归一化/标准化
- [ ] 只给主观权重不说明理由（AHP 的判断矩阵要有一致性检验 CI/CR）
- [ ] 评价结果只排序不解释（要说清"为什么它排第一"）
