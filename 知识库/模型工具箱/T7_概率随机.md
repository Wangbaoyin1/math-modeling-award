## 一句话核心

随机题 = "处理不确定性"。关键第一步是**识别随机性在哪 + 用什么概率模型描述**：是随机模拟求期望？状态转移？排队等待？多方博弈？

## 常用方法对照

| 方法 | 适用 | 典型题 |
|------|------|--------|
| 蒙特卡洛模拟 | 复杂系统求数值解/期望 | 积分、可靠性、风险 |
| 马尔可夫链 | 状态随机转移 | 天气、人口、股票 |
| 排队论 | 到达-服务系统 | 银行、呼叫中心 |
| 博弈论 | 多方策略决策 | 竞争、谈判 |
| 随机过程 | 随机演化 | 布朗运动、泊松过程 |

## 代码模板（⚠️ 赛前需在真实环境验证）

### 1. 蒙特卡洛模拟（估计 π，演示思想）
```python
import numpy as np
np.random.seed(42)                 # 固定种子保证复现
N = 100_000
x = np.random.uniform(-1, 1, N)
y = np.random.uniform(-1, 1, N)
inside = (x**2 + y**2) <= 1
pi_est = 4 * inside.mean()
print("pi ≈", pi_est)
```

### 2. 蒙特卡洛求期望（通用框架）
```python
import numpy as np
def mc_expectation(f, sampler, N=100_000):
    return f(sampler(N)).mean()    # f 是任意目标函数，sampler 生成样本

# 例：E[X^2]，X ~ N(0,1)
val = mc_expectation(lambda s: s**2, lambda n: np.random.randn(n))
print("E[X^2] ≈", val)             # 理论值 = 1
```

### 3. 马尔可夫链（状态转移）
```python
import numpy as np
def markov(P, x0, n):
    """P: 转移概率矩阵(每行和为1)；x0: 初始状态索引；n: 步数。"""
    states = [x0]
    for _ in range(n):
        states.append(np.random.choice(len(P), p=P[states[-1]]))
    return states
```

### 4. 排队论（M/M/1 关键指标）
```python
# λ: 到达率, μ: 服务率, 需满足 λ < μ（否则队列无限长）
lam, mu = 3.0, 4.0
Lq = lam**2 / (mu * (mu - lam))    # 平均排队长度
Wq = Lq / lam                       # 平均等待时间
print("平均排队人数 =", Lq, "平均等待 =", Wq)
```

## 关键点与坑（失败模式）

- [ ] 蒙特卡洛要**固定 seed + 足够样本量**（否则结果不可复现、误差大）
- [ ] 马尔可夫链要看**是否收敛到平稳分布**（别拿还没收敛的样本下结论）
- [ ] 排队论要满足 **λ < μ**（到达率 < 服务率），否则队列无限长
- [ ] 博弈论要明确**纳什均衡/策略空间**，别只算一个"最优解"
- [ ] 随机模拟要给**置信区间**（体现专业度）
