# 算法知识卡 07：污染源反演与溯源（进阶）

> 定位：**"找到污染/异常从哪里来"**——问法常见于"确定污染源位置""分析污染主要原因""追溯排放源"。
> 触发特征：题目给了**空间采样浓度场 + 采样点坐标**，要反推**源位置、源强、各源贡献**。
> 本篇补 2011A 真题暴露的短板：单源各向同性高斯拟合 R²≈0（0.003~0.046）时，如何升级到**可辩护的多源反演**。

## 0. 先判断反演的可做性（诚实分级，最重要）

| 等级 | 条件 | 能做 | 方法 |
|------|------|------|------|
| **L3 严格反演** | 有气象（风速风向）、水文、排放清单、时间序列 | 定量源强 + 源位置 + 贡献率 | 高斯烟羽反演 / 受体模型(PMF/CMB) / 贝叶斯 |
| **L2 空间统计定位** | 只有空间浓度场（+功能区/地形） | 源区域定位 + 相对源强 | 梯度场 + 峰值聚类 + 扩散核量级估计 |
| **L1 描述性溯源** | 只有浓度（无坐标/无功能区） | 定性"谁污染最重、可能主因" | 富集系数 + PCA 共源因子 |

> 铁律：**有几斤数据做几斤结论**。只有空间场就老实说"定位到源区域（描述性）"，不要硬报一个 R²=0.005 的 σ 当"反演结果"。2011A 正是 L2 场景——插件诚实披露后以梯度+聚类+功能区为主证据是对的，本篇让它更系统。

## 1. L1/L2 通用前置：把浓度场标准化

**富集系数** R = C/B（实测/背景）统一不同量纲元素；**综合污染指数**（内梅罗 P_N）或**潜在生态风险 RI** 作多元素合成标量场——后续梯度/聚类都在这个标量场上做。
- 单因子指数 P_ij = C_ij/B_j
- 内梅罗 P_N = sqrt((P̄² + P_max²)/2)
- 地累积 I_geo = log2(R/1.5)
- 潜在生态风险 RI = Σ T_j·R_ij（毒性系数 T：Hg=40,Cd=30,As=10,Cu=Ni=Pb=5,Cr=2,Zn=1，Hakanson）

## 2. L2 空间统计定位（只有浓度场时的主力）

### 2.1 峰值点反演（基线，别只用它）
取每元素浓度最大采样点作为源候选，记录坐标+富集+功能区。**局限**：峰值点≠源点（源在峰值点上游、受扩散/地形偏移），且多源叠加时峰值可能被"次峰"掩盖。→ 必须与下面 2.2/2.3 交叉。

### 2.2 浓度梯度场指向（升级）
对插值场（IDW/克里金）数值差分求 ∇C = (∂C/∂x, ∂C/∂y)。**污染物自源向外衰减时，梯度指向浓度增大的方向 = 源的方向**。画梯度矢量场，看箭头汇聚区。这是"峰值点"的空间结构增强——箭头汇聚中心比孤零零的最高点更可信。

### 2.3 热点聚类（合成多源）
把各元素峰值点坐标做 K-means（k 由肘部/轮廓系数定），聚成若干"源区域"。再用**功能区交叉**佐证：源区域落在工业区/交通区 → 人为源；落在山区 → 自然源。三者（峰值+梯度+聚类）一致才算定位。

### 2.4 扩散衰减核的"量级估计"用法（别当拟合）
设 C(r)=C₀·exp(−r²/2σ²)，对 ln C ~ r² 拟合得 σ。**注意**：单源各向同性假设在真实多源场下 R² 必然低（2011A 就是 0.003~0.046）。正确用法：
- σ 只报**量级**（"污染羽流尺度 ~2.5~4.8 km，与城区同量级 → 长期弥散累积而非孤立突发点源"）；
- **明确声明拟合失效**，把 σ 降级为"影响尺度估计"，源定位改以 2.1-2.3 为主证据。
- 这是"诚实披露 + 方法降级"的规范写法，评委认可。

## 3. L3 严格反演（有气象/水文/时间数据时）

### 3.1 高斯烟羽模型（点源连续排放，有风速风向）
稳态高斯烟羽（沿风 x、横风 y、垂向 z）：
```
C(x,y,z) = Q/(2π u σ_y σ_z) · exp(−y²/2σ_y²) · [exp(−(z−H)²/2σ_z²) + exp(−(z+H)²/2σ_z²)]
```
Q=源强，u=风速，H=有效源高，σ_y/σ_z 随下风向距离的经验扩散参数（Pasquill-Gifford 稳定度分类）。
**反演**：已知多受体点浓度 + 气象，用最小二乘/最大似然反演 Q 和 H；多源时叠加求和，源位置用网格搜索或非线性优化。

### 3.2 受体模型——土壤/沉积物溯源的"正规军" ★★★
高斯烟羽需要排放过程数据（常缺），而**受体模型只用受体（采样点）浓度 + 源成分谱**就能分离多源贡献，是环境溯源的标准方法：
- **CMB 化学质量平衡**：C_ij = Σ_k g_ik·f_kj（受体 i 元素 j 浓度 = 各源 k 贡献 × 源 k 的元素谱）。已知源谱 f（来自文献/本地源采样）时，最小二乘解贡献 g。
- **PMF 正矩阵分解**：C = G·F + E，同时反演源贡献 G 和源谱 F（无需先验源谱），非负约束，用 PMF5 / `scikit-learn NMF` 实现。
- **APCS-MLR 绝对主成分得分-多元线性回归**：PCA 得主成分 → 绝对主成分得分（APCS）→ 对元素浓度多元线性回归 → **各源贡献率**。无需源谱、比纯 PCA 多一步"定量贡献"，是源解析论文里最常配 PCA 的升级。
- **PCA/因子分析**（L1 版）：无源谱时用主成分载荷聚类识别"共源因子"（如 PC1=工业-交通复合源、PC2=Hg 独立点源），只能定性。

### 3.2b 逆扩散反演（"定位"的正解，区别于"拟合衰减曲线"）★★★
把污染源**位置 s_k 与源强 Q_k 当未知量**，用扩散方程逆问题直接反演：
```
C_obs(x) ≈ Σ_k Q_k · G(x, s_k; σ_k)        （G 为高斯核/格林函数）
min_{s,Q,σ} Σ_i [C_obs(x_i) − Σ_k Q_k G(x_i,s_k,σ_k)]² + λ·R(s,Q)   （R=正则化，抑病态）
```
- 决策变量是**源坐标**（不是"先固定峰值点再拟合"）→ 源位置自动最优；
- 求解：多初值 `scipy.optimize.least_squares`（`method='trf'`）+ 差分进化全局搜；源数 k 由 AIC/BIC/肘部定；
- 检验：**合成场 vs 实测场的残差空间分布图**（残差随机、无空间聚集 = 反演充分）；
- 与 §2.4 的"单源拟合看 R²"本质不同：这是**全空间联合反演**，σ、Q 一起解，R² 低也能定位（因为允许多源叠加）。无气象数据时 σ/Q 仍有不确定性 → 配 §3.3 贝叶斯给区间。

### 3.3 贝叶斯源强估计（有不确定性时）
把源强/源位置当随机变量，先验 + 似然（高斯噪声）→ 后验，用 MCMC（`pymc`/`emcee`）采样，输出源强的**后验分布 + 可信区间**（而非单点值）。适合数据噪声大、要给"估计不确定性"的题。

## 4. 多源混合反演的工作流（推荐串联）

1. **标准化**：富集系数/RI 合成标量场（§1）；
2. **粗定位**：峰值点 + 梯度场 + 热点聚类 → 候选源区域（§2）；
3. **分源反演**：对每个候选源，用局部数据做高斯核拟合得 σ、源强相对值（§2.4，诚实报 R²）；
4. **若有源谱/气象**：升级到 CMB/PMF 或高斯烟羽，定量贡献率（§3）；
5. **验证**：反演源强与功能区/排放先验交叉；合成场（Σ 各源预测）与实测场的残差空间分布图；留一交叉验证。

## 5. 关键坑（呼应失败模式库）

- [ ] **别把峰值点当源点**（#7 优化深度不足的变体）：峰值受扩散/地形偏移，需梯度+聚类交叉。
- [ ] **单源高斯拟合 R² 低是常态**，不是代码错：如实报告并降级为量级估计，别硬凑 R²。
- [ ] **量纲要统一**：Cd/Hg 是 ng/g、其余 μg/g，富集前先各自除各自背景值（无量纲），别混着比。
- [ ] **毒性系数别编**：RI 的 T 用 Hakanson 标准值（有文献依据），灵敏度分析重点扰 Hg（T=40 最大）。
- [ ] **源数量别拍脑袋**：K-means 的 k 用肘部/轮廓系数/先验功能区数，别固定 k=4 就完事。
- [ ] **背景值假设要声明**：附件背景值代表"人为干扰前本底"是强假设，若背景值本身被污染会低估富集。
