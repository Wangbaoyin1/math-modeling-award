# GPT-Image-2 图示生成 · 调用工具与提示词库（建模流程图/框架示意图/逻辑框图）

> 用途：数学建模论文中的**结构性示意图**（流程图、模型框架图、逻辑框图、关系图）用 GPT-Image-2 生成，质量高且"学术黑白+中文+含公式"，可直接插入论文；**数据/坐标类图**（时程、分布、灵敏度、功率面、扰动图）必须用 matplotlib（AI 生图坐标会乱），见 `图表库.py`。
> 已验证：一次调用生成 TOPSIS 学术黑白流程图，中文无乱码、含公式、虚线阶段标注，分辨率 1254×1254。

---

## 一、调用命令（已验证可通）

> 前提：本机 `node` 可访问你配置的图像 API。脚本位于 `aishumo/tools/gptimage2_gen.mjs`；安装后位于 `~/.dsh/skills/aishumo-method/tools/gptimage2_gen.mjs`。
>
> 需要设置环境变量：`GPTIMAGE_API_KEY`、`GPTIMAGE_BASE_URL`（可选 `GPTIMAGE_OUT_DIR`，默认当前目录 `图片AI/`）。

```powershell
node "aishumo/tools/gptimage2_gen.mjs" "<提示词>" [quality: low|medium|high] [size: 1024x1024|1024x1536|1536x1024]
```
- 示例：
```powershell
node "aishumo/tools/gptimage2_gen.mjs" "学术黑白流程图，数学建模TOPSIS算法框架，线条简洁，无多余装饰，中文标签，高清PNG，适合论文插入" high 1024x1024
```
- 输出：`图片AI/gptimage2_<前12字>_<时间戳>.png`
- 质量档：**默认 `low`**（对论文黑白流程图已够用、更稳更省）；若需更精细（含公式细节/小字物理符号）才用 `high`。
- 尺寸：按需选 `1024x1024`（方）| `1024x1536`（竖）| `1536x1024`（横）；论文流程图常用 `1024x1024`，长流程可用 `1536x1024`/`1024x1536`。

> 提示：脚本只从环境变量读密钥，不会把 Key 写入仓库；不要把真实 Key 贴进提示词或论文。

## 二、通用提示词模板（参数化，换【】即用）

**主模板**：
```
学术黑白流程图，数学建模【XXX框架】，线条简洁，无多余装饰，中文标签，高清PNG，适合论文插入。
结构：自上而下 3 层——【输入/前提】→【核心模块步骤】→【输出/结论】，直角箭头连接，节点圆角矩形，
文字为无衬线中文，配色仅黑白灰，背景纯白，无阴影、无渐变、无3D、无水印。
```

**进阶增强**（让图更"论文级"）：
- 右侧加**虚线"阶段/模块"标注框**（如"数据收集""标准化处理"……）——本版已验证效果好；
- 允许**核心公式**内嵌节点（如 TOPSIS 的 D_i^±、C_i）——gpt-image-2 能正确渲染公式；
- 改为**横向**：将"自上而下"改"自左向右，水平流程"。

## 三、那几类图的提示词（直接套用）

**1）通用数学建模流程图**（新框架/方法流程图）
```
学术黑白流程图，数学建模【通用算法/XX方法】求解流程，线条简洁，无多余装饰，中文标签，高清PNG，适合论文插入。
开始→准备数据/参数→建立模型函数→数值求解(迭代/优化)→结果输出→误差与灵敏度检验→结束。
直角箭头，圆角矩形，黑白灰，无装饰。
```

**2）机理/动力学建模框架**（本题波浪能示例）
```
学术黑白流程图，波浪能浮子-振子耦合建模框架，线条简洁，中文标签，高清PNG，适合论文插入。
自上而下：波浪激励(线性微幅波)→浮子(垂荡+纵摇，水动力=附加惯性+兴波阻尼+静水恢复)→
PTO(弹簧+直线阻尼/扭转弹簧+旋转阻尼)→振子(沿轴滑动+随轴转动)→相对运动驱动阻尼器做功→
平均输出功率→优化最优阻尼系数。右侧虚线标注各模块阶段，黑白灰。
```

**3）优化算法流程**（遗传/差分进化/模拟退火）
```
学术黑白流程图，遗传算法(GA)求解优化问题流程，线条简洁，无多余装饰，中文标签，高清PNG，适合论文插入。
初始化种群→计算适应度→选择→交叉→变异→新一代→判断(是否达迭代上限或收敛)→输出最优解(菱形判断)。
圆角矩形+菱形，直角箭头，黑白灰，无装饰。
```

**4）评价/决策方法流程**（TOPSIS/熵权/AHP/层次分析）
```
学术黑白流程图，TOPSIS评价算法框架，线条简洁，无多余装饰，中文标签，高清PNG，适合论文插入。
构建决策矩阵→确定指标属性并赋权→归一化与加权→确定正负理想解→计算距离→计算相对接近度→按C_i排序得评价结果。
含 C_i=Di−/(Di++Di−) 公式，右侧虚线阶段标注，黑白灰。
```

**5）模型关系/对比流程图**（多模型比较、模型递进）
```
学术黑白框架图，数学建模多模型对比与验证流程，线条简洁，中文标签，高清PNG，适合论文插入。
三个并排候选模型A/B/C→各输出结果→统一评价指标(误差/灵敏度/稳健性)→择优→结论。
直角连线，黑白灰，无装饰。
```

**6）问题递进/求解路线图**（赛题多问递进）
```
学术黑白流程图，XX赛题四问递进求解路线，线条简洁，中文标签，高清PNG，适合论文插入。
问题一(基础模型)→问题二(单参数优化)→问题三(多自由度扩展)→问题四(双参数优化与机理)→统一检验。
自上而下循环箭头，右侧标注每问核心方法，黑白灰。
```

**7）数据/建模流程泳道图 / 逻辑框图**（带角色/模块分区）
```
学术黑白流程泳道图，数学建模【数据→模型→求解→写作】全流程，线条简洁，中文标签，高清PNG，适合论文插入。
横轴阶段：数据准备/机理建模/数值求解/结果检验/论文写作；纵轴角色：建模者/工程师/审稿人；黑白灰，无装饰。
```

## 四、适用范围与"别踩的坑"
| 图型 | 用 GPT-Image-2 | 用 matplotlib |
|---|---|---|
| 流程/框架/逻辑框图/关系图/泳道图 | ✅ 强项（本工具） | 可但费劲 |
| 含公式的示意流程 | ✅ 能渲染公式 | 需 mathtext |
| 数据时程/灵敏度/功率面/分布/扰动/等高线 | ❌ 坐标会乱 | ✅ 必须（图表库.py） |
| 装置/几何示意图 | ✅（需提供准确几何描述，否则易歪） | ✅ 更精确（Patch 绘制） |

**核心提醒**：GPT-Image-2 适合"结构/流程/概念示意"，**不适合"依赖精确数值与坐标的数据图"**；两者搭配：结构图用本工具，数据图用 `图表库.py`。
