# T8 · 数据预处理与特征工程（工具箱）

> 用途：数据题的第一步，永远是"洗数据"。垃圾进垃圾出——数据没处理好，后面模型再牛也白搭。
> 方法论对齐 UltraMath《数据预处理与特征工程》，本篇补**可运行代码模板**。

## 一句话核心

拿到数据**先别急着建模**，先做四件事：理解 → 清洗 → 变换 → 特征工程。这四步的质量直接决定后面所有模型的上下限。

## 四步流程

| 步骤 | 做什么 | 关键 |
|------|--------|------|
| 1 数据理解 | 规模、类型、缺失、分布 | `df.info()`、`df.describe()` |
| 2 清洗 | 缺失值、异常值、重复值 | 见下 |
| 3 变换 | 标准化、归一化、编码 | 见下 |
| 4 特征工程 | 提取、选择、降维 | 构造对目标有用的特征 |

## 代码模板（⚠️ 赛前需在真实环境验证）

### 1. 数据理解
```python
import pandas as pd
df = pd.read_csv("data.csv")
df.info()            # 列类型、缺失情况
df.describe()        # 数值列统计量（均值/分位数/极值）
df.isnull().sum()    # 每列缺失数
```

### 2. 缺失值处理
```python
df.fillna(df.mean(), inplace=True)   # 数值列均值填充（最常用）
df.dropna(subset=["关键列"], inplace=True)  # 关键列缺失则删行
```

### 3. 异常值检测（IQR 法，比 3σ 更稳健）
```python
Q1 = df["x"].quantile(0.25)
Q3 = df["x"].quantile(0.75)
IQR = Q3 - Q1
mask = (df["x"] < Q1 - 1.5 * IQR) | (df["x"] > Q3 + 1.5 * IQR)
print("异常值数量 =", mask.sum())
```

### 4. 标准化 / 归一化
```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
X_std  = StandardScaler().fit_transform(X)   # z-score，均值0方差1
X_norm = MinMaxScaler().fit_transform(X)     # 缩放到 [0,1]
```

## 关键点与坑（失败模式）

- [ ] 聚类/PCA/距离类算法 → 用**标准化**；神经网络 → 可用归一化
- [ ] 缺失值填充**要说明理由**（均值/中位数/插值，为什么这么选）
- [ ] 异常值**别盲目删**——它可能是重要信号（如突发销量峰值）
- [ ] **训练/测试别一起标准化**（会泄漏测试集信息），先切分再分别变换
- [ ] 类别变量要编码（one-hot / 标签编码），别直接当数值喂
