> 方法论对齐 UltraMath《机理分析类》《差分方程模型》《系统动力学》《复杂网络与 Agent-Based 建模》，本篇补**可运行代码模板**。

## 一句话核心

机理题 = "找到系统演化的内在规律，写成方程再数值求解"。和"数据驱动"相反，机理模型**从原理出发**，优势是可解释、可外推；难点是**参数要有物理意义和来源**。

## 常用方法对照

| 方法 | 适用 | 典型题 |
|------|------|--------|
| 常微分方程 ODE | 连续时间演化 | 传染病、人口、运动 |
| 偏微分方程 PDE | 空间 + 时间 | 传热、扩散、波动 |
| 差分方程 | 离散时间演化 | 种群、迭代系统 |
| 系统动力学 | 反馈回路、存量流量 | 生态、经济系统 |
| 元胞自动机 / ABM | 个体交互、涌现 | 交通、人群疏散 |

## 代码模板（⚠️ 赛前需在真实环境验证）

### 1. 常微分方程数值解（scipy）
```python
import numpy as np
from scipy.integrate import solve_ivp

def dy(t, y):
    return -0.5 * y          # dy/dt = -0.5 y（指数衰减）

sol = solve_ivp(dy, [0, 10], [1.0], t_eval=np.linspace(0, 10, 100))
print(sol.t[:5], sol.y[0][:5])   # sol.y[0] 是解序列
```

### 2. 差分方程（递推迭代）
```python
def logistic(x0, r, n):
    xs = [x0]
    for _ in range(n):
        xs.append(r * xs[-1] * (1 - xs[-1]))   # 逻辑斯蒂映射 x_{n+1}=r·x_n(1-x_n)
    return xs
```

### 3. 系统动力学（SIR 传染病，存量-流量）
```python
def sir(S0, I0, beta, gamma, days):
    S, I, R = [S0], [I0], [0.0]
    for _ in range(days):
        dS = -beta * S[-1] * I[-1]
        dI =  beta * S[-1] * I[-1] - gamma * I[-1]
        dR =  gamma * I[-1]
        S.append(S[-1] + dS)
        I.append(I[-1] + dI)
        R.append(R[-1] + dR)
    return S, I, R
```

## 关键点与坑（失败模式）

- [ ] ODE 求解要**选对方法**：刚性系统（快慢时间尺度）用 `method="BDF"/"Radau"`，别用默认 RK45
- [ ] 参数要有**物理意义 + 来源**（题目给/文献/拟合），别凭空编
- [ ] 机理模型**必须检验**：拿模型结果与真实数据/现象对比（否则评委质疑"你凭啥说这方程对"）
- [ ] 参数估计（拟合）与机理推导要**结合**：先机理定结构，再数据定参数
- [ ] 时间步长要够细，否则数值解发散
