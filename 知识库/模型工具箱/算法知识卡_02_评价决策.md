# 算法知识卡 02：评价决策类（p15-17 AHP / p18 TOPSIS / p27 模糊 / p28 主成分）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角
> 一句话定位：**评价类赛题（"排序/优选/评级"）四大主力**——AHP 定权重、TOPSIS 排方案、模糊综合做等级评判、主成分降维+定权。

## 0 先判断题型：评价类问题三形态
- ① 分类（把对象分堆）；② 排序/比较（直接排优劣）；③ 考察综合目标实现程度（需参考系，如小康/现代化程度）。
- 赛题字眼："评价""比较""排序""评级""适宜性""优先级" → 评价类。

## 1 层次分析法 AHP（p15 原理 / p16 一致性 / p17 编程）

**本质**：复杂多准则决策 → 分层（目标层 Z→准则层 A→方案层 B）+ 两两比较打分 → 权重。
**适用**：指标无法直接量化、专家/主观判断主导的决策（选方案、评优先级）。Saaty 1970s 提出。

**四大步骤（必背流程）**：
1. **建立层次结构模型**（目标层 / 准则层 / 方案层树图）；
2. **构造判断矩阵**：不把全部因素一起比，而是**两两比较**，用 Santy **1-9 标度**（1 同等、3 稍重、5 明显、7 强烈、9 极端，倒数=反向）；心理上限：**每层因素 ≤ 9 个**；
3. **层次单排序 + 一致性检验**：求最大特征根 λmax 对应归一化特征向量 w 作权重；
4. **层次总排序 + 一致性检验**：自上而下合成 B 层对总目标权值。

**一致性检验公式（必须写进论文）**：
- CI = (λmax − n)/(n − 1)；RI 查表（n=1..15）；CR = CI/RI；
- **CR < 0.1 通过**，否则返回改判断矩阵。
- 例（视频案例 6 阶）：λmax=6.1232，w=(0.3794,0.2488,0.1604,0.1024,0.0655,0.0434)，CI=0.0246，RI=1.24，CR=0.0198<0.1 ✓

**编程要点（视频 Matlab 代码）**：`eig(A)` 取最大特征值对应特征向量 → `w=abs(V)/sum(abs(V))` 归一化 → CR 判断。RI 表：`[0 0 0.52 0.89 1.12 1.26 1.36 1.41 1.46 1.49 ...]`（注意 n=1,2 时 RI=0）。

**坑**：判断矩阵是**正互反矩阵**（aij=1/aji 对角=1）；两两比较一致性差是常态，CR 超限要回退调整——论文里写"经调整后 CR=…通过检验"即可。

## 2 TOPSIS（p18）

**本质**：把 m 个方案看作 n 维空间 m 个点，比谁**离正理想解最近、离负理想解最远**（贴近度 C）。
**适用**：多属性决策、已有指标数据的对象排序（比 AHP 更客观，数据可量化时首选）。

**完整流程**：
1. 决策矩阵 aij（m 方案 × n 属性）；
2. **属性类型处理**：效益型越大越好、成本型越小越好、**区间型**（如生师比最佳区间 [5,6]）用分段线性函数转到 [0,1]；
3. **向量规范化**：`bij = aij / sqrt(Σᵢ aij²)`（各方案同属性平方和=1，专为欧氏距离设计——此步与其它归一化不同，别用错）；
4. 加权（与 AHP/熵权法结合定权 w）；确定正理想解 x*（各列最优）、负理想解 x⁻（各列最劣）；
5. 算距离 D⁺、D⁻ → 贴近度 C = D⁻/(D⁺+D⁻)，C 大者优。

**写作价值**：步骤 2 的"指标类型处理表"（原始值→处理值）是评委爱看的规范数据处理示范。

## 3 模糊综合评价（p27）

**本质**：因素集 U → 评语集 V，用**隶属度**刻画"某人/物属于某等级的程度"，加权合成得综合隶属 → 最大隶属度定级。
**适用**：评价结果本身是**等级/程度**（水质等级、风险等级、满意度），指标含模糊语言。
**归一化三法**（写论文三选一）：
- 线性比例变换法（正向）：x'ij = aij / maxⱼ aij ∈ (0,1]；
- 极差变换 / 其他按类型处理。
**流程**：定因素集 U 与评语集 V → 定权重（AHP/熵权）→ 建模糊评判矩阵 R（隶属度）→ B = w∘R → 归一化 → 最大隶属度原则定级。

## 4 主成分分析 PCA（p28）

**本质**：把 p 个相关变量转成少数**互不相关**的主成分 F₁,F₂,…（协方差阵特征向量为系数），方差递减。
**用途（竞赛双杀）**：① **降维**（指标多且相关时先 PCA 再进模型）；② 客观定权（按贡献率或直接用主成分得分替代原始多指标）。
**前提检验（必写）**：
- KMO 检验（偏相关是否过小；**KMO>0.5~0.6 才适合**，0.59 是视频案例的临界值）;
- Bartlett 球形检验（原假设相关矩阵=单位阵；**p<0.05 拒绝→适合 PCA**）。
**选主成分个数标准**：特征根 >1（Kaiser）或 **累计贡献率 ≥ 80%**（课件另一处写 F1+F2>70%，常用 80/85%）→ 写清楚用哪个标准。
**特点**：主成分间 cov=0；第 k 个主成分贡献率 = λk/Σλ。
