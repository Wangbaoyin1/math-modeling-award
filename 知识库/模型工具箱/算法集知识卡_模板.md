# 算法知识卡模板（老哥算法集 → 竞赛应用）

> 用途：把老哥算法集视频的"核心知识/方法"沉淀成竞赛可查的知识卡。
> 每卡抓 4 件事：①一句话本质 ②适用赛题场景 ③关键步骤/公式 ④坑与写作要点。

## 卡结构

```markdown
### 算法名（老哥集号 + 视频主题）
- **本质**：一句话说清它在做什么。
- **适用场景**：什么赛题/什么数据用（配正向+反向例子：什么时候不要用）。
- **核心流程**：编号步骤 / 关键公式。
- **参数与坑**：易错点、边界条件、收敛注意。
- **竞赛写作**：论文里怎么描述（模型名、符号、检验指标）。
- **工具箱对应**：`图表库.py` / 自建函数 / sklearn / scipy 哪个可用。
- **关联真题**：哪年哪题用上了（来自国奖论文拆解）。
```
