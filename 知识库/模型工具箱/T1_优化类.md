# T1 · 优化类模型（工具箱）

> 用途：A/B 题高频。核心是**把现实约束和目标翻译成标准优化模型**，再选对求解器。
> 方法论对齐 UltraMath《优化类》《凸优化与非线性规划》《多目标优化》《启发式优化》，本篇补**可运行代码模板**。

## 一句话核心

优化题 = "在约束下求最优解"。关键不是"会调用求解器"，而是**把题目翻译对**：目标函数是什么？决策变量是什么？约束有哪些？——翻译错了，求解器再快也是白算。

## 优化问题分类与适配

| 类型 | 特征 | 求解器 | 典型题 |
|------|------|--------|--------|
| 线性规划 LP | 目标/约束全线性 | scipy.linprog / pulp | 简单资源分配 |
| 整数/混合整数规划 | 变量取整数 | pulp / scipy.milp | 种植方案、选址 |
| 非线性规划 NLP | 目标或约束非线性 | scipy.minimize | 定日镜、几何优化 |
| 动态规划 DP | 多阶段决策 | 手写递推 | 多期库存、路径 |
| 多目标优化 | 多个冲突目标 | 加权法 / NSGA-II | 效率 vs 成本 |
| 启发式 | NP 难、大规模、无梯度 | GA/PSO/差分进化 | 大规模调度、TSP |

## 代码模板（⚠️ 赛前需在真实环境验证）

### 1. 线性规划（scipy）
```python
from scipy.optimize import linprog
# 标准形是最小化 min c·x，最大化要取负号
res = linprog(
    c=[-3, -5],              # 目标系数（取负 = 最大化 3x+5y）
    A_ub=[[1, 0], [0, 2], [3, 2]],  # 不等式约束 A_ub·x <= b_ub
    b_ub=[4, 12, 18],
    bounds=[(0, None), (0, None)],  # x, y >= 0
    method='highs',
)
print("x =", res.x, "最优值 =", -res.fun)
```

### 2. 整数/混合整数规划（pulp）
```python
import pulp as pl
prob = pl.LpProblem("plant", pl.LpMaximize)  # 最大化
n = 3
x = pl.LpVariable.dicts("x", range(n), lowBound=0, cat="Integer")
c = [10, 8, 6]; a = [2, 1, 3]; b = 12
prob += pl.lpSum(c[i] * x[i] for i in range(n))        # 目标
prob += pl.lpSum(a[i] * x[i] for i in range(n)) <= b   # 约束
prob.solve()
print("最优值 =", pl.value(prob.objective),
      "解 =", [pl.value(x[i]) for i in range(n)])
```

### 3. 非线性规划（scipy）
```python
from scipy.optimize import minimize
import numpy as np
def obj(x):
    return (x[0]-1)**2 + (x[1]-2.5)**2          # 最小化目标
def cons(x):
    return x[0] + x[1] - 3                        # g(x) >= 0 约束
res = minimize(obj, x0=[0, 0], method="SLSQP",
               constraints={"type": "ineq", "fun": cons},
               bounds=[(0, None), (0, None)])
print("x =", res.x, "最优值 =", res.fun)
```

### 4. 多目标（加权法，最实用）
```python
def obj_weighted(x, w=(0.6, 0.4)):
    return w[0] * f_cost(x) + w[1] * f_time(x)  # 加权成单目标
# 再扫一组 w 画出 Pareto 前沿
```

### 5. 启发式 / 全局优化（差分进化，无需梯度）
```python
from scipy.optimize import differential_evolution
import numpy as np
res = differential_evolution(
    lambda x: (x[0]-2)**2 + np.sin(3*x[1]),   # 任意黑箱目标
    bounds=[(-5, 5), (-5, 5)],
    seed=42,                                   # 固定种子保证复现
)
print("x =", res.x, "最优值 =", res.fun)
```

## 关键点与坑（失败模式）

- [ ] `linprog`/`minimize` 默认**最小化**，最大化要取负号（最易踩）
- [ ] 整数规划**别用 linprog**（会给出小数解，不符合整数要求）
- [ ] 非线性规划会**陷入局部最优** → 多起点验证，或用差分进化做全局
- [ ] 启发式要**固定 seed + 多次运行取最优**（否则结果不可复现，评委质疑）
- [ ] 约束要写全：变量**非负性、整数性**别漏
- [ ] 求解前先**降维/化简**，别让求解器去啃一个 10^6 变量的模型
