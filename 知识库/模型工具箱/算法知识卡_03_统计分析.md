# 算法知识卡 03：统计分析类（p19 聚类 / p25 回归 / p26 拟合）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角

## 1 聚类分析（p19）

**本质**：无监督——把样本按特征相似度分成若干类，**类内相似、类间差异大**。
**适用**：① 给对象分类/划区域（省价分类、客户分群）；② 作为其它模型的前处理（先聚类再分别建模，常能提升精度）；③ 找异常/模式。
**主要流派**：
- **系统聚类（层次聚类）**：自底向上逐步合并最近类。类间距离可选**最短距离法（单连接）**、最长距离、平均距离、Ward（离差平方和）。输出**谱系图（树状图）**。
- **K-means**：指定 k，迭代：每点归最近质心 → 重算质心 → 直至稳定。图 6.2 三步演示(a)(b)(c)。
- 视频案例：辽宁/浙江/河南/甘肃/青海 5 省 1991 消费数据 8 指标（人均粮食/副食/烟酒茶/…/非商品支出）分类——**指标体系先定清楚**。
**关键点**：
- 数据先**标准化/归一化**（量纲不同，欧氏距离会失真）；
- k 如何定：肘部法则（SSE 拐点）、轮廓系数；
- 结果画**谱系图/散点染色图** → 图表库直接出。

## 2 回归分析（p25）

**本质**：有监督——找 y 与 x₁..xₖ 的（线性）函数关系，用于**解释影响 + 预测**。
**适用**：数据成对、y 连续 → 回归；赛题问"哪些因素影响 y/预测 y"（价格、产量、指标预测）。
**流程**：
1. **散点图看关系**（线性？指数？）→ 选模型形式；
2. 一元：y=ax+b 最小二乘；
3. 多元线性：y = β₀+β₁x₁+…+βₖxₖ；**检验**：
   - **F 检验**：H₀: 所有 β=0；F = [U/k]/[Qe/(n−k−1)] ~ F(k, n−k−1)，F 大拒绝 H₀ → 线性关系显著；
   - **r/复相关系数检验**：R = √(U/Lyy)，R² 越近 1 拟合越好；**F 与 R² 检验等价**（F=[(n−k−1)/k]·R²/(1−R²)）。
4. 逐步回归（筛选变量）、残差分析（检验假设）。
**写作**：论文写"经 F 检验 p<0.05 显著、R²=0.xx，模型可信" + 残差图（随机散布 = 好）。
**坑**：先看散点图别上来就线性；多重共线性（方差膨胀因子 VIF）导致系数不稳 → 可用逐步回归/PCA/岭回归缓解。

## 3 曲线拟合（p26）

**本质**：给定数据点，找一条**函数曲线 y=f(x)** 逼近（不要求过每点），使误差平方和最小。
**与插值的区别（必考概念）**：插值要求**曲线过所有数据点**（数据本身可靠时用，如分段插值/样条）；拟合允许偏离，**数据有噪声/要揭示规律时用**。
**核心两步（视频强调）**：
1. **线型选择**（难点！）：凭专业知识 + **散点图形态**定（线性/多项式/指数/对数/幂）；
2. **参数计算**：线性模型 → 最小二乘；非线性模型 → **Gauss-Newton 迭代**（scipy.optimize.curve_fit 即 Levenberg-Marquardt 变体）。
**写作价值**：强调"先画散点图判断线型"——这是建模素养展示；拟合优度报 R²/RMSE。
