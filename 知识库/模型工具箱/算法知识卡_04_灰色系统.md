# 算法知识卡 04：灰色系统（p20 关联 / p21 预测 GM(1,1)）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角
> ⚠️ 先看坑：**小样本、数据不足、规律不明显的"灰色"对象**才用；数据多且规律强时用统计/机器学习更好（失败模式库 #3 血泪教训：灰色预测边界）。

## 1 灰色系统与关联分析（p20）

**本质**：部分信息已知、部分未知的系统。**灰色关联分析 = 不看分布、不看样本量**，用几何曲线形状相似度度量因素间关联大小。
**用途（竞赛高价值）**：**因素筛选/影响排序**——"哪些指标对结果影响大"（替代或补充相关性分析；样本少、非线性时很稳）。
**竞赛真题（视频点名）**：
- CUMCM2003A SARS 传播
- CUMCM2005A 长江水质评价与预测
- CUMCM2006A 出版社资源配置
- CUMCM2006B 艾滋病疗法评价与预测
- CUMCM2007A 中国人口增长预测

**核心概念**：
- 灰关联分析找**发展趋势相似性**（几何形状贴近 = 关联大）；
- 参考序列（母序列）= 结果/被解释量；比较序列（子序列）= 候选因素；
- 计算灰色关联度 rᵢ：先初值化（各序列同一起点）→ 求差序列 Δᵢ(k)=|x₀(k)−xᵢ(k)| → 两级最小/最大差 → 关联系数 ξᵢ(k) = (min+ρ·max)/(Δᵢ(k)+ρ·max)，ρ=分辨系数（常 0.5）→ 平均得关联度。

## 2 灰色预测 GM(1,1)（p21）

**本质**：对原始数据**累加生成（AGO）**找出指数规律 → 建一阶线性微分方程 dx/dt+ax=b（白化方程）→ 解出后**累减还原（IAGO）**预测。
**适用**：**小样本（数据点少，≥4 个即可）、短期趋势预测**。经典题：SARS、人口、GDP、销量短期预测。
**GM(1,1) 建模步骤**：
1. 原始序列 x⁽⁰⁾（非负、≥4 点）；
2. **1-AGO 累加生成** x⁽¹⁾（k）=Σx⁽⁰⁾(i)；
3. 紧邻均值生成 z⁽¹⁾(k) = ½[x⁽¹⁾(k)+x⁽¹⁾(k−1)]；
4. 白化方程离散化：x⁽⁰⁾(k)+a·z⁽¹⁾(k)=b → 最小二乘求参数 a（发展系数）、b（灰作用量）；
5. 解微分方程得 x⁽¹⁾ 预测 → **IAGO 累减还原** x⁽⁰⁾(k)=x⁽¹⁾(k)−x⁽¹⁾(k−1)（k=1 时取 x⁽¹⁾(1)）得原序列预测；
6. 检验：**后验差比值 C / 小误差概率 p**（C<0.35 优、<0.5 合格）；必要时残差修正。
（视频详例：x⁽¹⁾=(5,9,14,24,35,46)→累减还原 x⁽⁰⁾=(5,4,5,10,11,11)。）

**坑（务必记住）**：
- **数据非负**；有负值/跳变先平移；
- 发展系数 |a| 太大（a>0.3~0.5）模型不可靠——预报中长期失效，只做短期；
- 数据本身非线性/振荡强 → 用 GM(1,1) 幂模型/残差修正，或干脆换回归/神经网络；
- 论文要报 **C、p 检验 + 预测表格**，别只丢一条曲线。

## 组合套路（竞赛常见）
- **灰色关联定因素 → 灰色预测定趋势**（关联选主因再预测）；
- 与 BP 组合：GM(1,1) 捕捉趋势 + 神经网络修正残差（GM-BP 组合模型，加分写法）。
