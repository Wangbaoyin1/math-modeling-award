# 算法知识卡 05：复杂系统类（p34 图论 / p35-36 BP / p39 元胞 / p43 马尔可夫）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角

## 1 图论（p34）

**本质**：把对象当**顶点**、关系当**边**，用图结构建模 → 最短路/树/流/匹配问题。
**定义**：图 G=(V(G), E(G))，V 非空有限顶点集 + E 边集。有向/无向、加权/无权。
**竞赛四大家**：
| 问题 | 问法 | 算法 |
|---|---|---|
| 最短路 | "从 A 到 B 最短/最快/最省钱路径" | Dijkstra（单源非负）、Floyd（全源，允许负权） |
| 最小生成树 | "连通所有点且总代价最小"（布线/管网/公路） | Prim、Kruskal |
| 网络最大流/最小费用 | 输送、分配流量最大/最省 | Ford-Fulkerson、费用流 |
| 匹配 | 指派（谁干哪活最优） | 匈牙利算法（可与整数规划互证） |
**应用场景**：物流配送路径、交通网络、通信布线、社交网络、电网。配**网络拓扑图**（networkx 画）。
**写作**：画图 + 表（距离矩阵→结果路径）；复杂度交代一句（Dijkstra O(n²)/堆优化）。

## 2 BP 神经网络（p35 上 / p36 下）

**本质**：多层前馈网络 + **反向传播**调权（误差 e=½Σ(d−yo)² 沿梯度回传），万能逼近非线性映射。
**结构**：输入层 n → 隐含层 p → 输出层 q。符号：输入 x、隐含层输入 hi/输出 ho、输出层输入 yi/输出 yo、期望 d、误差函数 e=½Σ(d_k−yo_k)²。
**适用（竞赛预测/分类黑箱）**：非线性回归预测（销量/价格/参数）、模式分类（好坏/等级）、需要"学习数据规律"时。**样本要够、要做归一化、要留验证集防过拟合。**
**流程**：归一化数据 → 划分训练/测试 → 建网（隐含层节点数经验公式）→ 训练（学习率、动量、最大迭代）→ 测试精度（MSE/R²/正确率）→ 画拟合对比图。
**改进写法（加分）**：GA/PSO 优化初始权值阈值、自适应学习率、与灰色/回归做组合对比。
**坑**：① 先标准化；② 隐含层/学习率靠试，别吹"最优"；③ 与**回归/灰色预测做对照表**证明"神经网络更好/更差"——竞赛里对照比自嗨有说服力。

## 3 元胞自动机 CA（p39）

**本质**：离散时空网格，每个**元胞**状态由**自身+邻居**按**局部规则**同步演化——用简单规则涌现复杂行为。
**要素**：元胞空间（一维只有 1 种划分；二维可**三角形/四边形/六边形**网格）、状态集、邻居（r 半径）、**局部映射规则 f**。
**初等元胞自动机**：状态 {0,1}、邻居半径 r=1：`Sᵢᵗ⁺¹ = f(Sᵢ₋₁ᵗ, Sᵢᵗ, Sᵢ₊₁ᵗ)`（8 种邻域组合 → 256 规则，如生命游戏/交通流）。
**适用（竞赛特定题）**：**空间-时间演化的物理/社会过程**——交通流（车流走走停停）、疫情/火灾传播、人群疏散、森林火灾、城市扩张、排队形成。
**写作**：定义元胞（网格大小/边界条件）→ 邻居 → 规则（写清几条 if-then 演变规则，评委看物理合理性与规则依据）→ 演化动画/热力图（多时刻并排图）→ 统计量随时间的曲线。

## 4 马尔可夫链（p43）

**本质**：随机过程，**未来只依赖当前状态、与过去无关**（无后效性/马氏性）：
P{ξₙ₊ₘ=j | ξₙ=i, 过去…} = P{ξₙ₊ₘ=j | ξₙ=i}。
**适用**：系统有离散状态且"状态按概率转移"——库存、天气、顾客状态、市场占有率、可靠性。经典**视频案例**：需求近似泊松（均值每周 1 架）的库存问题：周末库存 0→订 3 架 → 周初库存 {1,2,3}，用**转移概率矩阵**描述 → 求**稳态分布**算长期失去销售机会概率、周均销量。
**流程**：定状态集 → 统计/计算一步转移概率矩阵 P（行和=1）→ 预测 n 步 Pⁿ 或求稳态 π=πP → 由稳态做长期指标。
**坑**：转移矩阵要**行随机**；状态划分要穷尽且互斥；样本少时概率估计要平滑。
