# 算法知识卡 01：优化规划类（p6/p7/p8/p13）

> 来源：老哥算法集视频抽帧精读 · 竞赛应用视角

## 1 线性规划 LP（p6 原理 / p7 实战）

**本质**：目标函数与约束全线性，求 min/max cᵀx。

**适用场景**：资源分配、生产计划、运输调度、下料、投资组合——**一切"怎么分配/调度/选择使某指标最优"且关系线性**的问题。国赛几乎每年出现（如 2023B 多波束、2024A 板凳、下料/指派/运输）。

**核心流程（建模三步）**：
1. 定**决策变量 x**（能穷尽所有方案的量）；
2. 写**目标函数**（价值向量 f）；
3. 列**约束**（资源 ≤、需求 ≥、平衡 =、非负/上下界）。
→ 化成 Matlab/Python 标准形：`min cᵀx, s.t. Ax≤b, Aeq·x=beq, lb≤x≤ub`；求 max 时把 c 取负。

**关键细节**：
- 每个约束要能对应**一句物理/业务解释**（评委看这个）。
- 数据规模大时先检查稀疏性、可解性；无可行解 → 检查约束冲突（常是漏了某隐含约束）。

## 2 多目标 → 单目标的三种写法（p7 投资问题 1998A 精髓）

同一问题不要只给一个模型，老哥示范了**一个案例逐步加深模型**的写法：

- **模型一**：直接做单目标（如收益最大）→ 太粗糙；
- **模型二**：固定一个目标为约束（固定盈利 k → 极小化风险）；
- **模型三**：加权合成 `min s·(风险) − (1−s)·(收益)`，s∈(0,1] 为**偏好系数** → 可作 s 的灵敏度分析画出 Pareto 前沿。

> 竞赛价值：把"双目标/多目标"写成**加权单目标 + 参数扫描**是万能招，还能顺势做灵敏度分析（老哥作图体系呼应）。

**经典技巧（交易费线性化）**：分段函数交易费（xᵢ≤uᵢ 时按 uᵢ 收）在 uᵢ 相对 M 很小时，净收益近似 (rᵢ−pᵢ)xᵢ —— **先做合理近似再建模**是评委爱看的建模功力。

## 3 整数规划 IP（p8）

**本质**：LP + 部分/全部变量取整。0-1 变量表达"选/不选"。

**适用场景**：指派问题、选址、投资决策（0-1）、下料、排班——**决策本质离散**时。
- 0-1 建模万能模式：`xᵢ∈{0,1}` 表示选项目 i，总资金 ∑aᵢxᵢ ≤ A，总收益 ∑bᵢxᵢ。
- **下料问题**（例1）：xⱼ = 用第 j 种下料方式的根数，约束按每种零件需求累计 ≥ 需求量 → 经典的"方案枚举+整数规划"组合。

**坑**：整数规划规模一大就 NP-hard，别硬解——先看能否用**枚举可行下料方式**降维（下料题标准做法）；求解器 SciPy `milp` / `scipy.optimize`、`pulp`、`ortools` 均可。

## 4 非线性规划 NLP（p13）

**本质**：目标或约束含非线性项。

**适用场景**：投资组合风险度量 max{qᵢxᵢ} 是**不可微**目标 → 可等价转为 LP（加变量 t：min t, s.t. qᵢxᵢ≤t）；真正非线性用 fmincon/scipy.optimize.minimize。

**Matlab→Python 对照**：`fmincon('fun', x0, A, b, Aeq, beq, lb, ub, 'nonlcon')` ↔ `scipy.optimize.minimize(method='SLSQP'/'trust-constr')`，非线性约束分别写 g(不等式≤0)、h(等式=0) 回调。

**坑**：初值 x0 敏感、可能只到局部最优 → 多初值扫描 + 画目标函数形状确认（失败模式库 #6/#7 呼应：多策略混合、别锁死航向）。
