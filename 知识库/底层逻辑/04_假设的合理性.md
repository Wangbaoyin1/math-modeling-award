# M4 · 假设的合理性（底层逻辑）

> 用途：建模前先想清楚"我忽略了什么、为什么能忽略"，让模型既有数学可处理性、又抓住问题本质。
> 对齐国奖评阅"假设的合理性"（~25% 权重）。

## 一句话核心

模型是"**有目的的简化**"，假设是这种简化的**显式声明**。假设不是偷懒，是把无限复杂的现实砍到"数学能处理 + 能抓住本质"的规模。**假设错了，后面全盘皆错**，所以这一步值得花时间推敲。

## 假设的本质

- 每个模型都有假设，区别只在"**是否显式声明 + 是否合理**"。
- 好假设的三个特征：**抓本质**（保留了问题的关键机制）、**忽略次要**（砍掉不影响结论的细节）、**可检验**（能用违反后果说明边界）。

## 每条假设的写法（四要素）

每条假设必须写全四要素，缺一不可：

1. **陈述**：一句自然语言（"太阳光视为平行光"）；
2. **强度标签**：标 **[强]**（对结论影响大）或 **[弱]**（影响小）；
3. **理由**：为什么可以这么假设（"太阳距离远，光线近似平行"）；
4. **违反后果**：假设不成立会怎样（"否则须用锥形光束，模型复杂度暴涨"）。

## 数量与范围

- 通常 **4-6 条**。
- 太少 → 模型没简化，难以求解；
- 太多 → 模型脱离现实，失去意义（评委质疑"你这还是原题吗"）。

## 常见假设类型

| 类型 | 示例 | 通常强度 |
|------|------|---------|
| 理想化假设 | 忽略摩擦/损耗/大气衰减 | [弱] |
| 结构性假设 | 太阳光平行、镜面理想反射 | [强] |
| 数据假设 | 数据准确、缺失值可插补 | [弱] |
| 简化假设 | 近似线性、忽略二阶小量 | [强] |

## 国奖要点

- 假设合理性占评分 **~25%**，是四维之一。
- **与题目条件矛盾 = 一票否决（B3）**，这是最致命的错。
- 假设要"**服务于后面的建模**"，别写一堆用不上的。

## 常见陷阱（失败模式）

- [ ] 假设与题目矛盾（B3 一票否决，致命）
- [ ] 写"不考虑误差""忽略一切干扰"这类没意义的废话
- [ ] 假设太多，模型变成"理想世界"脱离现实
- [ ] 只有陈述，没有理由和违反后果（评委无法判断合理性）
- [ ] 假设和后面的模型对不上（写了却没用）

## 验收题（学习闭环）

给一道题，写出 4-6 条假设（每条含陈述 + [强]/[弱] + 理由 + 违反后果），检验是否真会：

> **【验收题】2022 CUMCM C「古代玻璃制品成分分析与鉴别」**：已知若干玻璃文物风化前后的化学成分（SiO₂、K₂O、PbO 等氧化物含量），要求分类鉴别玻璃类型，并分析风化对成分的影响规律。
>
> 请你写出 4-6 条建模假设（提示方向：风化对成分的影响、文物来源的独立性、成分数据的准确性等）。
