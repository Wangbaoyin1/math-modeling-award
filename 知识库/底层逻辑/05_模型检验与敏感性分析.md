## 一句话核心

评委要的不是"我算出来了"，是"**我算得靠谱**"。**检验三板斧**：
1. **误差分析**（证明正确）——拿结果跟真值对答案；
2. **灵敏度分析**（识别关键参数）——参数变一点，结果变多少、哪个参数影响大；
3. **稳健性检验**（证明普适）——换模型设定/样本/变量，结论会反转吗？

> ⚠️ 官方口径（2026 自查表）：**误差分析 + 灵敏度分析 + 稳健性分析 三大必备**，缺一个直接扣分。

## 一、误差分析（证明正确）

### 1.1 核心指标（先建"真实值 y / 预测值 ŷ / 残差 e=y−ŷ"三概念，所有指标都是对 e 的"拷打"）

| 指标 | 公式 | 特点 |
|------|------|------|
| 绝对误差 AE | $|y-\hat y|$ | 差了多少单位 |
| 相对误差 RE | $|y-\hat y|/|y| \times 100\%$ | **缺陷**：y 近 0 时爆炸/未定义 → 分母加小常数或改用 MAPE |
| MAE | $\frac{1}{n}\sum|y_i-\hat y_i|$ | 不放大离群点，看"典型偏差" |
| MSE | $\frac{1}{n}\sum(y_i-\hat y_i)^2$ | 放大离群点（平方） |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i-\hat y_i)^2}$ | 与 y 同量纲，最常用 |
| R² | $1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$ | 越近 1 越好；**陷阱**：加自变量必不降，哪怕加噪声 |
| 调整 R² | $1-\frac{(1-R^2)(n-1)}{n-p-1}$ | 对自变量数 p 惩罚，多变量时**报这个更严谨** |

**诊断技巧**：RMSE ≫ MAE 说明误差有厚尾（存在特别大的离群偏差）。

### 1.2 残差分析（R² 高≠模型好）
以预测值 ŷ 为横轴、残差 e 为纵轴画散点图。**好模型 = 零均值、等方差、无模式的混沌状态**（残差随机围绕 0 上下）。
- **喇叭形** = 异方差 → 加权/变换；
- **U 形曲线** = 未拟合非线性 → 加非线性项；
- **离群点** → 检查数据/稳健回归；
- **自相关**（时间序列）：ACF 图 + **DW 统计量**（0~4，≈2 无自相关，<2 正自相关，>2 负自相关）→ 加滞后项/广义最小二乘；
- **Q-Q 图**：检验残差正态性（点贴 45° 线=正态好；S 形/香蕉形=不满足 → 变换 y 或非参数/稳健回归）。t/F 检验都依赖正态假设。

### 1.3 泛化能力：交叉验证
训练集再好 ≠ 新数据好。**留出法**（80/20，但切一次不稳）→ **K 折交叉验证**（论文最常用，给箱线图）。

## 二、灵敏度分析（识别关键参数）

### 2.1 三大目的
识别关键参数 / 简化模型 / 评估鲁棒性。

### 2.2 相对灵敏度系数（核心公式，消除量纲、跨参数可比）
$$S(x_i)=\frac{\Delta Y / Y}{\Delta x_i / x_i}$$
- Δxᵢ/xᵢ = 参数变化率（如调高 10% 即 0.1）；ΔY/Y = 输出变化率；
- **解读**：S=2 表示参数变 1% 结果变 2%（高度敏感）；S=0.01 极不敏感；
- **弹性系数**（可导模型更精确）：$E=\frac{\partial Y}{\partial x_i}\cdot\frac{x_i}{Y}$，与上式在扰动极小时一致；
- 复杂数值模型用**有限差分近似**（小扰动 Δxᵢ 算差分）。

**例子（手算验证）**：Y=2x₁+3x₂，x₁=10,x₂=5 → Y=35。x₁ 加 10% → S(x₁)=0.571；x₂ 加 10% → S(x₂)=0.429。虽 x₂ 系数更大，但基准值小故敏感度低——**这正是相对灵敏度系数的价值**（绝对系数会误判）。

### 2.3 方法层次
局部（单因子扰动 OAT）→ 龙卷风图（国奖标配）；全局（Sobol/Morris，多参数联合方差贡献，用 SALib）。

## 三、稳健性检验（证明普适——≠灵敏度！）

**最容易混淆的点**（讲义四误区之三）：

| 维度 | 灵敏度分析 | 稳健性检验 |
|------|-----------|-----------|
| 变化对象 | **参数数值** | **模型设定/样本/变量定义** |
| 变化方式 | 连续扰动 ±x% | 结构性替换或删除 |
| 观察指标 | 输出变化量 | **结论方向与显著性** |
| 核心问题 | "哪个参数影响大？" | "**结论会反转吗？**" |
| 方法举例 | 扰动法、Sobol | 替换变量、子样本、变换模型 |

**稳健性策略**：
1. **替换核心变量**（换个衡量同一概念的指标，看结论是否一致）；
2. **改变样本区间/数据子集**（时间维度/横截面维度/分位数回归）；
3. 加入噪声检验、异常值处理、更换模型（如 PCA 换因子分析、IDW 换克里金）。

> 稳健性检验是证明"结论普适"的最强武器；通不过说明结论只是特定条件巧合。

## 四、写作建议（国奖规范，细节决定成败）

1. **单独开章节**，标题"模型检验与评价"，小节亮出三板斧：`5.1 误差分析`、`5.2 灵敏度分析`、`5.3 稳健性检验`——**不要混在模型建立里**；
2. **图文并茂、量化说话**：
   - 误差分析 → 指标对比表（训练集 vs 测试集）+ 残差图 + Q-Q 图 + K 折箱线图；
   - 灵敏度 → 龙卷风图 / 灵敏度系数排序柱状图 / 全局灵敏度饼图或热力图；
   - 稳健性 → 多组对照结果表 + 系数变化范围 + 系数森林图；
3. **逻辑自洽、解读到位**：为什么这个参数敏感？结合业务/物理机制说清楚；
4. **呼应建模**：灵敏度识别出的重要参数，正好对应前文重点讨论的机制。

## 常见误区（四误区，务必避开）

1. **只报喜不报忧**：残差有问题硬说完美——大方承认极端值表现欠佳 + 改进方向 = 加分项；
2. **灵敏度走过场**：不能空口"参数敏感"，必须给扰动比例 + 公式 + 数值；
3. **混淆灵敏度与稳健性**：扰动一个参数值不是稳健性检验，稳健性必须替换模型结构/样本/变量定义；
4. **检验与前面脱节**：检验要呼应建模（敏感参数 = 重点机制）。
