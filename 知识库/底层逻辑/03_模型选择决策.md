# M3 · 模型选择决策（底层逻辑）

> 用途：拿到题、做完框架后，**选对模型**——先定性"什么类型"，再定量"选哪个"，必要时组合。
> 对齐 UltraMath《方法选择决策树》《触发词索引》。

## 一句话核心

不要"套我会的模型"，要"**先定性这题是什么类型 → 在对应类型里选最合适的 → 必要时组合**"。选择依据是"问题特征 + 数据条件"，不是"我熟悉什么"。

## 三步决策法

### Step 1 · 题型识别（定性）

看题面关键词，先归类：

| 题型 | 题面信号词 | 一句话判据 |
|------|-----------|-----------|
| 优化类 | 最大/最小/最优/分配/调度/布局 | 在约束下求最优解 |
| 评价类 | 排名/评分/综合评价/哪个更好 | 给对象打分排序 |
| 预测类 | 未来/趋势/下一阶段/预测/演变 | 用历史推未来 |
| 机理类 | 机理/规律/演化/物理过程/动力学 | 找内在规律方程 |
| 统计类 | 关系/相关/差异/影响因素/显著性 | 从数据找关系 |
| 图论类 | 网络/路径/连通/覆盖/最短 | 节点与边的结构问题 |
| 随机类 | 随机/概率/排队/博弈/不确定性 | 有随机性的决策 |

> ⚠️ 一道题常是**混合题型**（如"预测 + 优化"），要识别出**主题型**和**辅助题型**。

### Step 2 · 模型匹配（定量）

每类题型下的候选模型（按复杂度递增）：

| 题型 | 候选模型（由简到繁） |
|------|---------------------|
| 优化类 | 线性规划 → 整数规划 → 非线性规划 → 动态规划 → 多目标 → 启发式(GA/PSO/模拟退火) |
| 评价类 | AHP → 熵权法 → TOPSIS → 模糊综合评价 → 灰色关联 |
| 预测类 | 回归 → 时间序列(ARIMA) → 灰色预测 → 神经网络 → 马尔可夫链 |
| 机理类 | 微分方程 → 差分方程 → 系统动力学 → 元胞自动机 → Agent-Based 建模 |
| 统计类 | 假设检验 → 方差分析 → 相关分析 → 聚类 → 主成分 → 因子分析 |
| 图论类 | 最短路(Dijkstra/Floyd) → 最小生成树 → 网络流 → 匹配 → TSP |
| 随机类 | 蒙特卡洛 → 排队论 → 马尔可夫过程 → 博弈论 |

### Step 3 · 选择依据（在候选中定哪个）

| 依据 | 判断 |
|------|------|
| 数据量 | 数据多 → 统计/ML；数据少/无 → 机理/灰色 |
| 问题结构 | 机制清晰 → 机理/优化；黑箱 → 数据驱动 |
| 可解释性 | 论文要讲清逻辑 → 偏机理/解析；纯预测 → ML 可以 |
| 求解可行性 | 必须**真能跑出结果**，别选跑不动/装不起的 |
| 评委观感 | 有理由 + 有对比 → 加分；"套模型" → 减分 |

### 模型组合（国奖常见套路）

- **主模型解题 + 辅助模型支撑**：如"机理主模型 + 数据修正项""优化主模型 + 预测提供参数""主成分降维 + 聚类"。
- 论文里至少做 **2 个模型的对比**（带量化指标），体现"比较过再选"。

## 国奖要点

- 选模型必须写**理由 + 1 个备选**：为什么选 A 不选 B（对比表：候选 + 评估维度 + 优良中差）。
- 常见论文句式：*"问题 X 本质上是一个【类型】问题；候选方法有 A/B/C；A 在【维度】最优，故采用 A。"*

## 常见陷阱（失败模式）

- [ ] 只套"我会的"模型，不管适不适配（评委一眼看出）
- [ ] 杀鸡用牛刀 / 复杂题用简单模型
- [ ] 只给结论，不给"为什么选它"的理由
- [ ] 模型选好但跑不出结果（求解可行性没评估）

## 验收题（学习闭环）

只判题型 + 列候选模型（不用真求解），检验是否真会"选模型"：

> ① 2021 CUMCM A「FAST 主动反射面调节」→ 题型？候选？
> ② 2022 CUMCM C「古代玻璃制品成分分析与鉴别」→ 题型？候选？
> ③ 2023 CUMCM C「蔬菜类商品的自动定价与补货」→ 题型？候选？
> ④ 2024 CUMCM C「农作物种植策略」→ 题型？候选？
>
> （提示：留意哪些是"优化 + 预测/统计"的混合题）
